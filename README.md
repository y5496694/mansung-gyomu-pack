# 만승 교무팩 · Mansung Gyomu Pack

> **처음 사용하시면 [필독문서 — 설치부터 사용까지](필독문서.md)를 먼저 읽으세요.** Windows용 ChatGPT 설치·Plus 이상 권장 환경·Codex 전환·Computer Use·브라우저 연결을 캡처 화면과 함께 설명합니다. 설치 후에는 [폴더별 쉬운 사용법](docs/폴더별_사용법.md)의 요청문을 그대로 말하면 됩니다.
>
> **AI 작업 전 필독:** [최상단 SKILL.md](SKILL.md). 일정·스케줄은 **이지에듀**, 학교 시간표는 **classtime**, 학부모 소통·공지·안내·가정통신문은 **하이클래스**, HWP/HWPX·한글 파일은 **읽기·요약도 나래한글**, 쪽지·대화·교직원 연락은 **CBE CLI**, 공문·기안·복무·출장·결재·접수는 **교무나래 포탈**로 처리합니다. 복합 요청은 단계별로 해당 도구를 함께 사용합니다.

**만승초등학교 교직원이 교무 업무에 사용하는 기능들을 모아둔 패키지입니다.**

한글 문서 읽기·작성·편집, 업무포털·나이스·에듀파인 업무, 충북소통메신저, 이지에듀 일정 관리, 하이클래스 학부모 소통, 공유시트 기본 시간표 기능을 한곳에서 설치하고 사용합니다. **필독 스킬 1개 + 6개 도구의 업무 스킬 9개, 총 10개**를 함께 설치합니다.

각 도구는 원본 저장소에서 계속 개발합니다. 만승 교무팩은 여섯 원본의 최신 `main`을 자동으로 가져와 `packages/`에 묶습니다. ZIP에도 실제 소스와 템플릿이 모두 포함됩니다.

## 제공 기능

### 1. 한글 문서 작성·편집 — 나래한글

- HWP/HWPX 문서 읽기, 구조 확인, 새 문서 생성과 기존 내용 수정
- 표 셀 병합·분할, 행 삽입·삭제, 셀 크기·여백·테두리·배경색 조정
- 글자 크기·색·굵게, 문단 정렬, 그림 크기·위치 조정
- 설치된 한컴오피스의 액션·COM 인터페이스를 통한 편집과 저장 후 검증
- 보고서·기안문·현장체험학습 계획서·연수 결과보고서·시간표·교수학습 지도안·평가표·연구대회 보고서·보도자료·가정통신문·회의록 등 **형식 템플릿 11종**
- 추진목적·기대효과, 안전지도, 결재·협조, 특수교육, 생활지도, 가정통신문 인사말 등에 쓰는 **문구 템플릿 7종**

자세한 사용법: [나래한글 안내](packages/narae_hangul/README.md)

### 2. 업무포털·나이스·에듀파인 — 나래교무 업무포털

- **업무포털:** 교육청 설정, 로그인·개인 인증서 절차, 나이스·K-에듀파인 진입
- **나이스 복무:** 연가·조퇴 초안 입력, 개인결재선 지정, 최종 상신 전 확인
- **에듀파인 문서등록대장:** 기간·제목·기안(접수)자 검색, 기안자·문서번호·기안일시 확인과 목록 정리
- **WXS 공문 조회:** 열린 공문의 본문과 첨부파일 목록·정보 확인
- **WXS 기안 준비:** 표준 양식의 제목·본문·비공개 사유·과제카드·결재경로·수신자·첨부·자동발송 속성 설정과 요청된 임시저장

현재 지원 단계는 조회·초안·임시저장까지이며, 최종 상신·결재 승인·공문 실제 발송은 지원하지 않습니다. 자세한 범위: [업무포털 안내](packages/narae_gyomoo_portal/README.md)

### 3. 교직원 소통 — 충북소통메신저

- 이름으로 교직원 검색: 내 조직 우선 검색, 필요 시 전체 조직 검색과 사용자 프로필 확인
- 받은·보낸·읽지 않은 쪽지 목록, 제목·내용 검색, 쪽지 본문과 첨부파일 정보 조회
- 대화방 목록·검색과 기존 대화 내용 조회
- 기존 1:1 대화 전송, 새 1:1·그룹 대화방 생성과 첫 메시지 전송
- 제목·본문을 지정한 쪽지 전송, `--dry-run` 사전 확인, 전송 결과 대조
- 일반 조회·전송을 메신저 창을 앞으로 띄우지 않고 백그라운드에서 처리

새 방 생성·쪽지 전송은 모의 시험과 실앱 사전 점검까지 확인된 기능입니다. 실제 새 방 생성·쪽지 발송의 전체 과정은 아직 실사용 검증하지 않았습니다. 자세한 사용법: [소통메신저 안내](packages/CBE_CLI/README.md)

### 4. 학교·개인 일정 관리 — 나래교무 이지에듀

- 오늘·특정 날짜·기간별 일정 조회
- 개인·학교·그룹·복무기타 일정 구분, 공휴일·국가절기를 포함한 표시 대상 일정 조회
- 날짜·제목·세부 내용·담당자를 지정한 일정 입력과 저장 후 재조회
- 서버 요청 없이 입력 내용을 확인하는 미리보기와 동일 일정의 중복 입력 건너뛰기
- 로그인한 이지에듀의 기존 학교·사용자 설정을 이용한 Windows CLI 실행

실제 일정 조회는 확인했으며, 일정 입력은 실제 데이터를 변경하지 않는 방식으로 검증했습니다. 실제 등록 후 앱 표시까지는 미검증입니다. 반복 일정 새 생성·수정·삭제·첨부·알림 발송은 포함하지 않습니다. 자세한 사용법: [이지에듀 안내](packages/narae-gyomoo_ezedu/README.md)

### 5. 학부모 안내·상담 — 나래교무 하이클래스

- 교직원 로그인과 대상 학교·학년도·학급 확인
- 학급 알림장 검색·조회·요약, 학부모 공지 초안 준비
- 공지의 읽음·미열람 현황 확인
- 하이톡 기존 대화 조회와 1:1 답장 준비
- 개인별 일괄메시지와 교사만 발언하는 단체 공지방을 구분한 연락 준비
- 예약 연락 준비와 게시·발송 직전 확인

로그인·기존 알림장·읽음 현황·하이톡 조회와 빈 작성 양식 표시를 확인했습니다. 실제 입력·게시·발송·예약은 실사용 검증하지 않았습니다. 자세한 절차: [하이클래스 안내](packages/narae_gyomoo_highclass/README.md)

### 6. 학급 기본 시간표 — 나래교무 기본 시간표

- 전체 공개 Google Sheets의 학년도·학기·학년·반·요일·교시를 AI로 해석
- 학교별 다른 양식, 가변 학년과 반 이름, 8교시 이상도 가능한 셀 매핑
- 조회일의 한국 날짜로 2~7월은 해당 연도 1학기, 8~12월 및 다음 해 1월은 2학기 선택
- 전체 학급 JSON과 학년·반 선택 HTML을 함께 갱신하고 최신 원본 기준 질문에 응답
- HTML을 열 때와 5분마다 원본 확인, 에이전트가 갱신한 JSON도 화면에 자동 반영
- 주간 과목별 시수에서 여러 과목을 선택해 시간표의 해당 과목을 함께 강조하고 개별·일괄 해제
- 반별 시간표 출력 버튼으로 선택한 반을 A4 인쇄·PDF 저장하고 선택 과목의 강조 색·테두리도 유지
- 표 배치·학급이 바뀌면 AI 재해석 요청, 갱신 실패 시 마지막 확인 시각과 자료 상태 표시
- 실제 공유시트 링크·학교별 매핑·추출 데이터는 Git에서 제외하고 PC의 설치 폴더에 보존

만승초등학교 원본의 2026년 1·2학기 각 22반 추출과 HTML 표시를 확인했으며, 학기 경계·다른 표 방향·8교시·로컬 설정 보존 등을 자동 시험했습니다. 기본 시간표를 다루므로 날짜별 행사·휴업·대체수업은 자동 추정하지 않습니다. 처음 연결하거나 배치가 바뀌면 에이전트에게 재조사를 요청합니다. 자세한 사용법: [기본 시간표 안내](packages/narae_gyomoo_classtime/README.md)

## 내려받기와 설치

[만승 교무팩 ZIP 다운로드](https://github.com/y5496694/mansung-gyomu-pack/archive/refs/heads/main.zip) 후 압축을 풀거나, Git으로 받습니다.

```powershell
git clone https://github.com/y5496694/mansung-gyomu-pack.git
Set-Location mansung-gyomu-pack
.\install.ps1
```

Windows와 Python 3.10 이상이 필요합니다. 기본 설치 위치는 `CODEX_HOME/skills`, 해당 환경변수가 없으면 사용자 폴더의 `.codex/skills`입니다. 설치 후 새 대화에서 스킬을 사용합니다.

처음 설치하는 일반 사용자는 명령어 대신 [필독문서의 설치 요청문](필독문서.md#6-만승-교무팩-내려받기와-설치)을 Codex에 붙여 넣어도 됩니다. 이미 설치한 경우에도 최신 팩으로 재설치·업데이트하고 **새 대화**를 열어야 필독 스킬과 강화된 적용 조건을 발견할 수 있습니다.

```text
나래한글로 이 한글 문서의 표 내용을 고쳐줘.
나래교무로 에듀파인 문서등록대장을 검색해 줘.
충북소통메신저에서 읽지 않은 쪽지를 보여줘.
이지에듀에서 이번 주 학교 일정을 조회해 줘.
하이클래스에서 우리 반 알림장과 읽음 현황을 확인해 줘.
이 공개 시간표 링크를 연결하고, 현재 학기 전체 학급 시간표를 HTML로 보여줘.
오늘 3학년 1반 3교시 과목을 최신 원본으로 확인해 줘.
```

다른 위치에 설치하려면 `./install.ps1 -SkillsDirectory 'D:\my-skills'`를 사용합니다. 이 옵션은 스킬 파일을 복사하는 위치만 지정하며 다른 에이전트의 등록 형식을 변환하지 않습니다.

기존 파일과 내용이 같으면 건너뛰고, 교체하는 기존 파일은 스킬 폴더 밖의 `skill-backups/mansung-날짜/`에 백업합니다. 기존의 `narae-gyomu-work-portal/references/portal.json`은 로컬 교육청 설정으로 보존합니다. 시간표의 `sources.local.json`, `mapping.local.json`, `data/`도 유지하므로 업데이트 뒤 같은 공유시트 링크를 계속 사용합니다. 배포본에 없는 기존 사용자 파일은 삭제하지 않습니다.

### 기능별 실행 환경

설치 명령은 스킬 파일을 배치합니다. 각 기능의 실행 환경은 별도로 준비합니다.

- **소통메신저:** Node.js 22.19 이상과 본인 계정으로 로그인된 충북소통메신저가 필요합니다. npm 의존성은 없습니다.
- **업무포털:** 브라우저 컨트롤이 연결된 브라우저와 학교 업무 시스템이 필요합니다. WXS는 설치된 클라이언트와 `pywin32`가 필요하며, 원본의 [설치 안내](packages/narae_gyomoo_portal/README.md#설치)를 따릅니다.
- **한글:** 사용하는 경로에 따라 한컴오피스·Python 라이브러리가 필요합니다. [나래한글 안내](packages/narae_hangul/README.md)와 설치된 스킬의 `references/hancom.md`를 확인합니다.
- **이지에듀:** 이지에듀 투게더에 로그인한 이력과 활성화된 일정 게이트웨이 모드가 필요합니다. 외부 Python 패키지는 사용하지 않습니다.
- **하이클래스:** 브라우저 컨트롤이 연결된 브라우저와 하이클래스 교직원 계정이 필요합니다.
- **기본 시간표:** Python 3.10 이상, 인터넷 연결과 다운로드 가능한 공개 Google Sheets 링크가 필요합니다. 외부 Python 패키지·AI API 키는 필요하지 않습니다. 설치 폴더의 `시간표 열기.cmd`로 HTML을 엽니다.

원본 도구의 지원 범위와 검증 상태는 각각의 README와 SKILL.md를 따릅니다.

## 업데이트

### GitHub의 만승 교무팩

GitHub Actions가 **매시간 17분**에 원본 여섯 저장소의 최신 `main` 커밋을 확인합니다. 변경이 있으면 가져온 파일과 설치 경로를 검사한 뒤 만승 교무팩에 자동 커밋합니다. Actions의 **Sync upstream packages → Run workflow**로 즉시 실행할 수도 있습니다.

GitHub의 예약 실행은 지연될 수 있습니다. 공개 저장소에 60일간 활동이 없으면 예약 작업이 비활성화될 수 있으므로, 장기 미사용 후에는 Actions 상태를 확인합니다. [GitHub 예약 실행 안내](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule)

원본 코드는 `packages/`에서 직접 수정하지 않고 해당 원본 저장소에서 수정합니다. 다음 동기화는 원본 내용으로 교체합니다. 아직 원본에 커밋·푸시하지 않은 PC의 변경은 포함되지 않습니다.

만승 교무팩의 필독·업무 분류는 팩 최상단 `SKILL.md`와 `routing/skill-overrides.json`이 관리합니다. 설치기는 원본 스냅샷을 변경하지 않고 **설치본**의 적용 설명과 필독 연결을 보강합니다. 원본의 상세 절차·승인·지원 한계는 유지합니다. 따라서 원본 자동 동기화 후에도 재설치 시 공통 규칙을 계속 적용합니다. 기존 전역 AGENTS.md나 사용자 설정은 변경하지 않습니다.

### PC에 설치한 스킬

```powershell
.\update.ps1
```

이 명령은 원본의 최신 `main`을 직접 받아 설치본까지 갱신합니다. Git으로 받았거나 ZIP으로 받은 폴더 모두에서 사용할 수 있습니다. 로컬 폴더의 `packages/`와 버전 기록도 갱신하므로 Git 사용자는 변경 상태를 확인합니다. 만승 교무팩 자체의 설치·갱신 스크립트 변경은 `git pull --ff-only` 또는 새 ZIP 다운로드로 먼저 받습니다.

GitHub 저장소가 갱신돼도 PC의 설치본이 저절로 바뀌지는 않습니다. 기본 구성은 이 업데이트 명령을 실행할 때 PC에 반영합니다.

## 버전과 출처 확인

`pack.json`은 구성할 저장소·브랜치·설치 경로를 지정합니다. `sources.lock.json`은 실제로 가져온 커밋 주소와 파일 내용의 SHA-256을 기록합니다. 텍스트 개행은 LF로 환산해 Windows의 개행 변환을 허용합니다.

`local_skills`는 팩 소유 필독 스킬에 설치할 파일을 명시합니다. 원본 파일 해시와 설치본 분류 보강은 별도로 검사합니다.

```powershell
python scripts/validate.py
python -m unittest discover -s tests -v
```

동기화 과정은 원본 코드를 실행하지 않습니다. 원본 스킬의 설치 경로·동일 이름 충돌·파일 해시를 검사하고, 임시 폴더에서 설치·업데이트·백업·설정 보존을 시험합니다. 학교 시스템 로그인이나 메시지 전송을 수행하지 않습니다. 각 도구의 모든 기능을 검증하는 통합 시험은 아닙니다.

## 구성

```text
mansung-gyomu-pack/
├─ 필독문서.md            일반 사용자용 설치·시작 안내와 캡처
├─ SKILL.md / AGENTS.md   AI 작업 전 필독·업무 분류
├─ references/            상세 분류와 복합 요청 예시
├─ routing/               설치본의 적용 설명·필독 연결 보강
├─ agents/                필독 스킬 표시 정보
├─ docs/                  폴더별 쉬운 사용법·설치 캡처
├─ packages/              원본 여섯 저장소의 소스·문서·템플릿
├─ scripts/               통합 동기화·검사·설치
├─ tests/                 설치·업데이트 검사
├─ .github/workflows/     자동 동기화
├─ pack.json              구성 목록
├─ sources.lock.json      반영된 원본 커밋·해시
├─ install.ps1            스킬 일괄 설치
└─ update.ps1             원본 최신 코드로 설치본 갱신
```

각 구성 요소의 라이선스·출처 고지는 원본 폴더에 유지합니다. 만승 교무팩 전체에 하나의 라이선스를 일괄 적용하지 않습니다. 자세한 내용은 [출처 안내](NOTICE.md)를 확인하세요.
