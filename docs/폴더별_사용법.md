# 폴더별 쉬운 사용법 — 명령어 대신 ChatGPT에 부탁하세요

먼저 [필독문서](../필독문서.md)의 설치를 마칩니다. 여기 나오는 폴더는 직접 실행할 프로그램 메뉴가 아니라 **ChatGPT가 읽는 설명과 실행 도구가 들어 있는 보관함**입니다. 아래 요청문을 대화창에 붙여 넣고 학교·학급·파일·날짜만 자신의 상황에 맞게 바꾸면 됩니다.

## 1. packages/narae-gyomoo_ezedu — 이지에듀 일정

**학교·개인 일정, 오늘 할 일, 주간 스케줄은 이 폴더입니다.** 날짜별 행사와 일정을 확인하며, 수업 시간표는 다음 classtime을 사용합니다.

미리 준비할 것: Windows에서 본인 이지에듀 투게더 계정으로 로그인한 이력이 있어야 하고 일정 게이트웨이 모드가 활성화되어 있어야 합니다. 외부 Python 패키지는 필요 없습니다. 설정이 안 맞으면 ChatGPT가 원인과 확인할 설정을 알려 줍니다.

그대로 요청해 보세요.

> 이지에듀에서 오늘 학교 일정과 이번 주 개인 일정을 나누어 알려줘. 날짜·시간·장소·담당자가 있으면 함께 정리해줘.

> 내일 오후 3시 학년 협의회를 개인 일정으로 넣을 내용을 먼저 미리보기로 보여줘. 장소는 회의실이야. 아직 저장하지 마.

> 방금 확인한 내용을 이지에듀 개인 일정에 등록하고 다시 조회해서 확인해줘.

결과에서 확인할 것: 조회 기간과 일정 종류가 맞는지, 미리보기인지 실제 저장인지 확인합니다. 시간이 제목이나 상세 설명에 기록될 수 있습니다. 학교 전체 일정으로 공유하는 것과 개인 일정은 다르므로 원하는 범위를 말해 주세요.

현재는 조회와 일정 입력을 제공합니다. 반복 일정 생성·수정·삭제·첨부·알림 발송은 지원하지 않습니다. 실제 조회는 확인했고, 실제 1건 등록 후 앱 표시까지의 실사용 검증은 아직 구분해서 봐야 합니다.

근거: [이지에듀 스킬](../packages/narae-gyomoo_ezedu/SKILL.md), [상세 안내](../packages/narae-gyomoo_ezedu/README.md)

## 2. packages/narae_gyomoo_classtime — 학교 기본 시간표

**학교 시간표·교시·과목·시수는 반드시 classtime입니다.** 선생님이 준 공개 Google Sheets를 읽어 학년과 반을 고르는 시간표 화면을 만듭니다.

미리 준비할 것: 다운로드 가능한 자기 학교의 공개 Google Sheets 시간표 링크, 인터넷, Python 3.10 이상입니다. API 키나 별도 AI 결제는 필요 없습니다. 비공개 자료를 임의로 공개하지 말고 공유 가능한 기본 시간표를 준비합니다.

처음 한 번은 이렇게 요청합니다.

> 이 공개 공유시트가 우리 학교 시간표야: [링크]. 학교명은 [학교명]이야. classtime 스킬로 모든 탭을 확인하고 학년도·학기·전체 학년과 반을 해석한 뒤 시간표 화면으로 보여줘.

그 뒤에는 다음처럼 말하면 됩니다.

> 오늘 3학년 1반 3교시가 무슨 과목인지 최신 원본으로 확인해줘.

> 3학년 1반 시간표에서 국어와 수학을 함께 강조해서 보여줘. 그 반 시간표를 A4로 인쇄할 수 있게 열어줘.

결과에서 확인할 것: 학년도·학기·학년·반과 원본 확인 시각입니다. ChatGPT는 질문마다 원본을 다시 조회합니다. 기본 시간표이므로 체험학습·임시 시간표·대체수업이 자동 반영되지는 않습니다. 그날 행사 일정도 필요하면 이지에듀를 함께 조회하게 합니다.

학교에서 표 배치를 바꾸면 “원본 배치가 바뀌었으니 다시 해석해줘”라고 요청합니다. `시간표 열기.cmd`는 시간표 화면을 여는 파일이지만 직접 실행이 어렵다면 ChatGPT에 화면을 열어 달라고 하면 됩니다. 연결 링크와 학급 데이터는 PC에 보존하고 공개 저장소에 올리지 않습니다.

근거: [classtime 스킬](../packages/narae_gyomoo_classtime/SKILL.md), [상세 안내](../packages/narae_gyomoo_classtime/README.md)

## 3. packages/narae_gyomoo_highclass — 학부모 소통·공지·안내·가정통신문

**학부모 공지, 공지사항, 알림장, 안내, 가정통신문, 학부모에게 연락하는 일은 하이클래스입니다.** 학부모와의 연락을 교직원 메신저로 보내지 않습니다.

미리 준비할 것: 하이클래스 교직원 계정, 연결된 브라우저, 현재 학교·학년도·학급입니다. 첫 로그인이나 추가 인증은 직접 처리합니다. [하이클래스](https://www.hiclass.net/)에 평소 쓰는 방식으로 로그인하세요. 예시에서 확인한 구글 로그인이 모든 사람의 필수 방식은 아닙니다.

> 하이클래스에서 올해 우리 반 알림장을 찾아 최근 공지 3개의 내용과 읽음 현황을 정리해줘. 조회만 해줘.

> 학부모에게 안내할 현장체험학습 가정통신문 초안을 준비해줘. 날짜는 [날짜], 장소는 [장소], 준비물은 [준비물]이야. 하이클래스 스킬을 참고하고 아직 게시하지 마.

> 이 가정통신문.hwpx를 나래한글로 읽고 하이클래스 알림장 문안으로 정리해줘. 학부모만 대상으로, 게시 직전 화면까지 준비해줘.

결과에서 확인할 것: 학교·학년도·학급, 학부모/학생 선택, 수신 인원, 첨부, 실제 게시 여부입니다. 문안을 만들었다고 게시된 것은 아닙니다. 하이톡의 **일괄**은 개인별 전달, **단체**는 단체방이므로 “학부모마다 따로”인지 “단체방”인지 알려 주면 좋습니다.

현재 실제 확인한 범위는 로그인, 기존 알림장·읽음 현황·하이톡 조회, 빈 작성 화면까지입니다. 실제 입력·게시·전송·예약의 실사용 검증과 구분합니다. 최종 전송은 요청한 범위와 현재 브라우저 도구의 확인 정책을 따릅니다.

근거: [하이클래스 스킬](../packages/narae_gyomoo_highclass/skills/narae-gyomu-hiclass/SKILL.md), [상세 안내](../packages/narae_gyomoo_highclass/README.md)

## 4. packages/narae_hangul — 한글 파일 읽기·요약·만들기·고치기

**HWP·HWPX·한글 문서라면 읽기만 해도 나래한글을 사용합니다.** “나래한글”이라는 이름을 매번 말할 필요 없이 “이 한글 문서 읽어줘”라고 해도 적용되는 규칙입니다.

미리 준비할 것: 원본 한글 파일과 Python 3.10 이상입니다. 실제 한컴에서 고급 편집·쪽수 확인을 할 때는 설치된 한컴오피스와 해당 실행 환경이 필요합니다. `setup`, `doctor --hancom` 등 진단은 ChatGPT가 안내합니다. 승인된 파일 접근 모듈이 필요한 경우 확인할 위치를 알려 달라고 하세요.

> 이 HWP 파일을 나래한글로 실제 읽고 본문과 표를 요약해줘. 읽지 못한 부분이 있으면 표시하고 원본은 바꾸지 마.

> 이 HWPX의 표 모양을 유지하고 ‘일시’ 셀 내용만 [새 날짜와 시간]으로 바꿔줘. 나래한글 CLI로 처리하고 결과를 다른 이름으로 저장한 뒤 확인해줘.

> 우리 학교 회의록 양식으로 한글 문서를 만들어줘. 참석자는 [명단], 안건은 [안건], 내용은 [내용]이야. 필요한 형식·문구 템플릿을 참고해줘.

결과에서 확인할 것: 실제 나래한글 실행 여부, 읽은 본문·표, 생성 파일 위치, 저장 후 검증 결과입니다. AI가 설명만 했거나 문서 구조를 자기 코드로 해체한 것은 이 팩의 나래한글 사용이 아닙니다. 실행할 수 없으면 그 이유를 밝히고 완료했다고 하지 않아야 합니다.

나래한글 안의 다섯 폴더도 직접 고칠 필요는 없습니다.

| 내부 폴더 | 쉽게 말하면 | ChatGPT에 부탁할 때 |
| --- | --- | --- |
| `1_나래엔진` | 실제 HWP/HWPX를 읽고 만드는 실행 도구 | “나래한글 엔진으로 읽고 실행 결과를 확인해줘.” |
| `2_나래스킬` | 양식·문구·조판 작업의 추가 지침 | “추가 나래스킬 지침도 참고해 양식을 유지해줘.” |
| `3_형식템플릿` | 보고서·기안문·계획서·회의록 등 양식 11종 | “현장체험학습 계획서 양식을 참고해 만들어줘.” |
| `4_문구템플릿` | 목적·기대효과·안전지도·가정통신문 인사말 등 문구집 7종 | “안전지도 문구집을 참고하되 이번 행사 내용으로 써줘.” |
| `5_유틸리티` | 표 조정·쪽수 검증·양식 추출 등을 돕는 보조 도구 | “지원되는 도구로 표를 조정하고 한컴 쪽수를 확인해줘.” |

팩 설치는 엔진 스킬과 그 실행 파일을 배치합니다. 형식·문구 템플릿과 추가 지침은 내려받은 팩 폴더에 있으므로 **다운로드 폴더를 지우지 말고** 필요할 때 그 위치를 알려 주세요. 설치된 엔진 스킬만으로 모든 템플릿이 복사되는 것은 아닙니다.

독립 엔진의 쪽 나눔은 한컴과 다를 수 있습니다. 최종 배포 전에는 한컴에서 레이아웃을 확인하는 것이 좋습니다. 공문 첨부 파일은 나래한글로 읽지만, 포탈에서 열린 공문 에디터 본문은 포탈의 WXS 도구로 읽습니다.

## 5. packages/CBE_CLI — 쪽지·대화·교직원 연락

**쪽지, 대화, 선생님에게 연락하는 일은 CBE CLI로 처리합니다.** 이 도구는 충북소통메신저에 연결되므로 다른 지역의 메신저를 자동으로 대신하지는 않습니다.

미리 준비할 것: 본인 계정으로 실행·로그인된 충북소통메신저와 Node.js 22.19 이상입니다. 평소 조회와 전송은 화면을 앞으로 띄우지 않고 처리합니다. 사용자가 CLI 명령을 직접 입력할 필요는 없습니다.

> 충북소통메신저에서 안 읽은 쪽지를 조회하고 중요한 내용부터 정리해줘. 답장이나 전송은 하지 마.

> 김 선생님을 내 조직에서 먼저 찾아줘. 없으면 전체 조직 후보를 소속과 함께 보여줘. 아직 보내지는 마.

> 방금 확인한 [이름·소속] 선생님에게 제목은 ‘협의회 안내’, 본문은 ‘내일 오후 3시 회의실에서 협의회가 있습니다.’인 쪽지를 보내줘. 보낸 기록으로 결과를 확인해줘.

결과에서 확인할 것: 받는 사람의 이름·소속, 본문 원문, 실제 전송 결과와 보낸 기록입니다. 동명이인이 있으면 대상부터 정해야 합니다. 전송 확인은 상대방의 열람 확인과 다릅니다. 본문이 없으면 새 방의 첫 메시지를 임의로 만들지 않습니다.

새 방 생성·쪽지 전송은 모의 시험과 실앱 사전 점검까지 확인되었고 실제 새 방 생성·쪽지 발송 전체 과정의 실사용 검증과 구분합니다. 첨부·예약·보안 쪽지 전송은 현재 지원하지 않습니다. 학부모에게 연락하는 요청은 하이클래스로 처리합니다.

근거: [CBE 스킬](../packages/CBE_CLI/skills/cbe-messenger/SKILL.md), [상세 안내](../packages/CBE_CLI/README.md)

## 6. packages/narae_gyomoo_portal — 교무나래 포탈

**공문, 기안, 복무, 출장, 결재, 접수는 교무나래 포탈입니다.** 폴더와 스킬에서 쓰는 현재 배포 이름은 **나래교무 업무포털**입니다. 두 이름은 이 안내에서 같은 팩을 가리킵니다.

미리 준비할 것: 학교 업무포털 계정과 사용할 인증서, 연결된 브라우저, 업무에 필요한 학교 프로그램입니다. 기본 교육청은 충북이며 다른 지역은 확인된 업무포털 주소와 로컬 설정을 맞춰야 합니다. 인증서 암호·개인 식별정보는 공개 파일이나 GitHub에 넣지 않습니다.

> 교무나래 포탈로 에듀파인 문서등록대장에서 이번 달 [검색어] 관련 공문을 찾아줘. 기간과 확인한 페이지도 알려줘.

> 나이스에서 [날짜] [시작시간]부터 [종료시간]까지 조퇴 신청 초안을 준비하고 결재선을 확인해줘. 최종 상신은 하지 마.

> 열린 WXS 공문의 본문과 첨부파일 목록을 확인해줘. HWP/HWPX 첨부 내용도 읽어야 하면 나래한글로 처리해줘.

> [출장/접수/결재 관련 요청]을 포탈에서 확인해줘. 현재 스킬이 지원하는 단계와 내가 직접 처리할 단계를 구분해줘.

결과에서 확인할 것: 조회한 문서·날짜·기안자, 입력한 초안, 실제 저장 여부, **최종 미상신 상태**입니다. WXS는 전용 도구로 처리하며 컴퓨터 유즈로 화면을 대신 눌러 우회하지 않습니다.

**출장·결재·접수라는 단어를 포탈로 연결하는 것과 그 절차가 모두 구현되었다는 것은 다릅니다.** 현재 최종 상신·결재 승인·공문 실제 발송은 지원하지 않습니다. 연가·조퇴 외 복무, 접수 처리 등의 추가 업무는 지원 상태를 확인해야 합니다. AI가 이지에듀에 일정을 넣었다고 출장 신청이 완료된 것은 아닙니다.

## 7. 최상단의 다른 폴더는 무엇인가요?

| 폴더·파일 | 역할 | 일반 사용자가 할 일 |
| --- | --- | --- |
| `필독문서.md` | 처음 설치하고 사용하는 안내 | 처음부터 읽기 |
| `SKILL.md`, `AGENTS.md` | AI가 먼저 읽는 필독 규칙 | 첫 설치·첫 요청에서 읽게 하기 |
| `references/`, `routing/`, `agents/` | 업무 분류표·설치 시 적용 규칙·스킬 표시 정보 | 직접 수정하지 않고 ChatGPT에 맡기기 |
| `docs/`, `docs/images/` | 이 사용법과 설치 캡처 | 필요할 때 열기 |
| `scripts/`, `tests/` | 설치·업데이트·검사 도구 | “설치해줘”, “업데이트해줘”, “검사해줘”라고 요청하기 |
| `pack.json`, `sources.lock.json` | 도구 목록과 가져온 원본 버전 기록 | 버전 문의 때 ChatGPT가 확인 |
| `.github/` | GitHub의 자동 동기화 설정 | PC에서 직접 조작할 필요 없음 |
| `install.ps1`, `update.ps1` | 일괄 설치·갱신 실행 파일 | ChatGPT가 실제 실행했는지 확인 |

도구가 자동 선택되지 않으면 **“최상단 필독 스킬을 먼저 읽고 해당 도구를 실제 실행해줘”**라고 요청하고 설치본 업데이트와 새 대화 여부를 확인합니다. 자세한 설치·연결 문제는 [필독문서](../필독문서.md)를 참고하세요.
