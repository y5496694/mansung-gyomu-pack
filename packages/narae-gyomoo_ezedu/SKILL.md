# 나래교무 이지에듀

스킬 폴더의 `scripts/easyedu_schedule.py`를 Python으로 실행한다. Windows 전용이며 외부 패키지는 필요 없다. GUI 조작 없이 기존 이지에듀 설정으로 요청한다.

## 조회

```powershell
python -X utf8 "<스킬 폴더>\scripts\easyedu_schedule.py" list --date 2026-10-15 --json
python -X utf8 "<스킬 폴더>\scripts\easyedu_schedule.py" list --from 2026-10-15 --to 2026-10-21 --kind school --json
```

날짜 생략 시 한국시간 오늘이다. `--date`와 기간 옵션을 섞지 않는다. 조회 기본값은 `--kind all`이며 타인의 개인 일정은 제외하고 그룹 일정에는 앱의 대상자·소속 조건을 적용한다. 날짜, 제목, 세부 내용, 작성자와 담당자 등 요청에 필요한 정보를 결과에서 추린다.

## 입력

```powershell
python -X utf8 "<스킬 폴더>\scripts\easyedu_schedule.py" add --date 2026-10-16 --title "협의회 15:00" --detail "장소: 회의실" --kind personal --dry-run --json
```

실제 등록 요청이면 확정된 날짜·제목·대상으로 `--dry-run`을 빼고 실행한다. 이미 사용자가 등록을 요청한 내용에는 별도 재확인을 요구하지 않는다. 초안·예시·미리보기 요청은 `--dry-run`을 유지한다. 필요한 날짜나 제목이 없으면 그 값만 확인한다.

`--kind`는 `personal`(개인, 기본값), `school`(학교), `group`(현재 소속 그룹), `other`(복무기타)다. 사용자 요청과 맥락으로 일정을 분류하고 공유 범위를 임의로 넓히지 않는다. `--assignee`로 담당자를 지정할 수 있다. 시간은 제목·세부 내용에 적는다.

`created`는 저장 ID 및 재조회 성공, `exists`는 같은 일정이 있어 추가하지 않은 상태, `preview`는 서버 요청 없는 미리보기다. 저장 응답 불명·재조회 실패 시 같은 날짜를 먼저 조회한다. 같은 입력의 자동 재전송·병렬 실행을 피한다.

## 운영 범위

- 현재 Windows 사용자의 기존 로그인·학교·게이트웨이 설정을 사용한다. 인증키를 출력·복사·저장하지 않는다. 로그인 비밀번호를 읽을 필요는 없다.
- 게이트웨이 모드가 꺼졌거나 인증이 거절되면 설정 확인을 안내한다. 다른 접속 방식으로 우회하지 않는다.
- 반복 일정 새 생성, 첨부, 쪽지·알림 발송, 수정·삭제는 지원하지 않는다.
- 실서버 조회와 변경 0건인 입력 API 검증을 마쳤다. 실제 1건 등록 및 앱 화면 반영은 미검증이다. 검증 상태를 설명할 때 이를 구분한다.

명령 옵션과 출력·제약의 상세 내용은 [README.md](README.md)를 참조한다.
