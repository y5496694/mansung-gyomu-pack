# 나래오피스 필수 10과제 1차 보완

현재 판정은 **불합격**이다. 사용자 지정 열 과제는 전부 필수이며 미지원·미검증도 불합격이다.

0.13.0-preview.20에서 전용 보안 문서 로그인, 6개월 쪽지·대화 원문 탐색, 본문 검색, 공람 두 목록의 전체 페이지/문서별 요약, 타인 특정일 복무 조회 보조, WXS 상신 후 문서처리와 서버 목록 검증을 보강했다. 출장은 입력 보조이며 결재·상신 완료 지원을 검증하지 못했다. 전체 과제 완료 또는 공개 배포 준비로 간주하지 않는다.

검증: 전체 자동 시험 234/234, 새 에이전트 합성 과제 5/5 통과. 실제 가중치 추가 학습은 하지 않았고 Office LoRA v1을 유지한다. 고정 조회는 제한된 실행기 판단 경로를 사용한다. 문서·포털 접속과 실제 전송·상신 검증을 구분한다.

| 과제 | 남은 사항 |
| --- | --- |
| 1. 보안 문서 로그인·나이스·에듀파인 진입 | 기존 포털 세션은 관찰했으나 두 시스템 업무 화면과 실제 자동 인증 완료 미검증 |
| 2. 6개월 쪽지·대화 제출 후보 목록 | 모의 102건 통과. 10월 29일 기존 실자료 1,112건에는 제한 9건·오류 1건이 있었음. 현재 6개월 쪽지·대화 전체 실기 미검증 |
| 3. 특정 내용 탐색·설명 | 대화 모의 실행 통과. 실제 계정의 쪽지·대화 두 변형은 별도 검증 필요 |
| 4. 특정 대상 쪽지·대화 전송 | 이번 벤치의 실제 수신자·전송 원문이 지정되지 않아 시험 발송하지 않음 |
| 5. 서식 준수 기안 상신 | 실제 서식·캡처·첨부 서버 해시·결재선·최종 상신의 종합 실기 미검증 |
| 6. 내가 처리 중인 문서 확인·설명 | 현재 계정 담당 범위·모든 페이지·실문서 본문/첨부 종합 실기 미검증 |
| 7. 공람 문서 모두 읽고 설명 | 모의 두 폴더 각 2페이지, 공문 4건 본문 전체·첨부 4개 정리 통과. 실계정 전체 미검증 |
| 8. 다른 사람 특정 날짜 복무 조회 | 모의 브라우저 2페이지 결과 통과. 실제 메뉴·권한·계정 결과 실기 미검증 |
| 9. 나이스 출장 상신 | 출장 결재 단계와 최종 신청 목록을 확인하는 완성된 실환경 절차가 아직 없음. 미상신으로 정지 |
| 10. 나이스 연가·조퇴 상신 | 두 종류 각각 실제 날짜·시각·사유·현재 결재선과 상신 후 목록 검증 미완료 |

실행 계약과 다른 PC의 설정은 `skills/narae-hangul-office/references/basic-benchmark.md`를 따른다. `narae-office bench`는 버전 고정 계약, `bench run.json`은 해시·JSON 원문 증거의 모든 검사와 변형을 판정한다. 모의 통과가 실환경 합격으로 바뀌지 않는다.

재현: `node experiments/narae-office-basic-10-20261031/run.cjs <D 드라이브 결과폴더>`. 실제 학교 네트워크를 사용하지 않는 합성 출처이며 실계정 인증이나 더미 상신을 수행하지 않는다. 이전 실패와 후속 수정 결과는 로컬 벤치 폴더에 함께 보존한다.
