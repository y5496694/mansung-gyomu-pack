# 나이스 에이전트 실행

나래3을 포함한 모든 연결 모델에 나이스 실행 지침을 자동 제공한다. 이 변경은 가중치 재학습이 아니라 앱의 도구 연결·화면 관찰·실행 절차 개선이다. 나래3의 기존 학습 어댑터는 유지한다.

- 나이스·복무 요청은 필요한 브라우저·포털 도구만 제공한다. 문서나 메신저가 함께 필요한 요청은 해당 도구도 유지한다.
- 현재 제어 화면을 먼저 관찰하고, 공지사항 팝업과 업무 프레임을 구분한다. 일반 Chrome의 로그인 세션과 앱의 제어 창은 자동 공유되지 않는다.
- WebSquare의 combobox·option·treeitem·tab을 읽는다. 모달 대화상자가 열리면 그 안의 항목을 우선 관찰한다. 최신 화면에서 관찰한 ref만 모델의 선택지에 제공한다.
- 연가/조퇴는 신청일자·시각·사유를 사용자 요청에서 확인하고, 이름과 순서를 실제 결재선에서 대조한다. 없는 값을 임의로 채우지 않는다.
- 근무상황신청의 승인요청과 기안문서상신의 최종 상신을 구분한다. 최종 상신은 지원하지 않는다.
- 관리형 나래AI는 실제 모델 토크나이저로 입력 크기를 확인한다. 현재 요청과 최근 관찰을 유지하면서 과거 작업 쌍을 줄인다. 화면이 너무 크면 필터 조회를 안내한다.
- 오류에는 문맥 초과·시간 초과·반복 작업 등의 원인을 표시한다. 진단 로그에는 프롬프트·화면·도구 인자·토큰을 기록하지 않는다.

현재 지원 범위는 확인된 연가/조퇴 초안과 개인결재선 지정이다. 다른 복무 종류나 학교별로 달라진 화면은 현재 관찰로 확인해야 한다. 로컬 합성 시험 통과가 모든 실제 나이스 화면의 성공을 보장하지는 않는다.

## 실행 승인

승인 요청은 설정과 별도인 **도구 실행 승인** 창에서 확인한다. 허용·거절·Esc로 결정하며, Esc와 닫기는 거절이다. 설정 탭은 이동하지 않는다.

**설정 → 일반 → 모든 도구 실행 자동 허용**을 켜면 문서 변경·브라우저 조작·메신저 발송의 개별 승인창을 생략한다. 변경 즉시 이 PC에 저장되고 재실행 후에도 유지된다. 끄면 다시 개별 승인을 요청한다. 작업 폴더·인자 검증과 로그인 직접 입력, 미지원 최종 처리 제한은 유지한다.

## 개발 검증

```powershell
node --test tests/*.test.cjs
node tests/approvals-desktop.cjs
$env:NARAE_REAL_MODEL_ROOT = 'D:\Codex\models\narae-office'
node tests/neis-model.cjs
```

모델 시험은 설치된 실제 나래3을 사용한다. 생성한 가상 인물과 로컬 합성 페이지를 사용하며 학교 서비스에 로그인하거나 실제 복무 신청을 만들지 않는다. 원본 개인 대화와 학교 화면을 학습 자료로 수집하거나 공개하지 않는다.
