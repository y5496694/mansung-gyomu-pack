# 0.9.0 검증 결과

2026-10-28 · Windows x64 · 한컴오피스 2022·2024 한글

- **단위 검증 13/13:** 기존 OAuth·연결 11개에 여러 한컴 버전 폴더 탐색·최신 우선 정렬 및 앱 전용 Python 우선 선택·외부 Python 검색 경로 차단을 더했다. 자동 설치된 Python 3.13.17로도 모두 통과했다.
- **실제 HWP/HWPX 작업:** 나래한글 엔진으로 문단과 2×2 표가 있는 합성 문서를 생성하고, 한글 2022·2024에서 각각 본문 교체·17pt 굵게 적용·현재 내용 재읽기·저장 후 재열기·PDF 출력 통과. 편집하는 동안 같은 한글 앱을 사용함을 확인했다.
- **원문 보호:** 오래된 liveRevision 편집 요청을 거절했다. 파일 엔진은 미저장 변경이 있는 한글 파일을 덮어쓰지 않는다.
- **미리보기:** 두 형식 모두 실제 한글 PDF 1쪽 출력과 PNG 미리보기 통과. PDF 출력 중 원본 해시가 바뀌지 않았다.
- **앱 통합:** 기본 OAuth 설정을 확인하고 모의 OpenAI API로 읽기 → 본문/서식 편집 → 결과 확인의 3요청을 실제 UI와 한글에서 수행했다. 저장한 최신 PDF 미리보기를 화면으로 확인했다.
- **한 번에 설치:** PATH를 Windows 시스템 폴더만 남긴 상태에서 Windows PowerShell 5로 `scripts/install.ps1`을 실행했다. Node.js·Python을 시스템에서 찾지 않고 공식 ZIP의 SHA256을 확인해 앱 폴더에 자동 설치했다. Node.js 24.22.1, Python 3.13.17, Electron과 Python 라이브러리 및 공식 Claude 로그인 CLI까지 자동 준비됐다.
- **설치본 통합:** 한글·공백을 포함한 별도 경로에서 자동 설치된 앱으로 한컴 2022·2024를 각각 선택해 실제 UI/AI 3요청/한글 편집 흐름을 통과했다. 외부 Python 경로 환경 변수 없이 앱의 `runtime/python`을 사용했다.
- **엔진 원본 대조:** 나래한글 엔진의 Python 24개 파일을 기준 커밋과 AST로 비교했다. 설명 주석·docstring을 제외한 실행 코드는 일치한다. 원 저작권·MIT 허가문은 유지한다.
- **공개 파일 점검:** 앱/엔진 소스·설치 스크립트·문서만 배포한다. 사용자 문서·계정 토큰·API 키·대화·설치 글꼴·한컴 실행 파일은 포함하지 않는다.

검증 문서는 일회용 합성 파일이다. OAuth·AI 서버는 모의 서버를 사용했으며 실제 사용자 계정 승인이나 유료 요청을 보내지 않았다. 다른 PC의 한컴 보안 정책과 글꼴 구성까지 동일함을 보장하지 않는다.

재현 명령:

```powershell
npm test
node tests/native-smoke.cjs
node tests/app-smoke.cjs
```

네이티브 검증에는 Windows와 한컴오피스 한글이 필요하다. 특정 버전은 `NARAE_HWP_EXE`로 지정할 수 있다. 2020·2018·기타 버전의 경로는 탐색하지만 실제 기능은 미검증이다. UI 통합 검증의 모델 서버는 로컬 모의 서버이며 외부 유료 API를 호출하지 않는다.
