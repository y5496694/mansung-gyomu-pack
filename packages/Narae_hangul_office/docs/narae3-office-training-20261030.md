추가 학습 후보를 별도로 공개하고, 현재 배포된 나래3 v1 가중치는 유지합니다. 도구 선택 정확도 향상이 확인되지 않았기 때문입니다. 이번 오피스의 개선은 모델 학습과 구분해 실행 제어·도구 명세·스킬에도 반영했습니다.

- 새 합성 대화 36건, 1 epoch, 새 optimizer update 9회, 학습률 1e-5입니다. 기존 기반 모델은 고정하고 마지막 6개 디코더 층의 rank 8 / alpha 16 LoRA를 학습했습니다.
- 학습 파라미터 2,752,512개, 변경된 LoRA 텐서 84개입니다. CPU NF4 학습과 Q4_K_M 기반 GGUF 추론의 양자화는 서로 다릅니다.
- 저장한 safetensors와 변환한 F32 GGUF의 84개 텐서를 비트 단위로 대조했습니다.
- 이번 데이터에는 실제 쪽지·대화·공문·학생 정보·인증 정보를 넣지 않았습니다. 개인 문서와 실행 기록은 공개 저장소·모델 업로드에서 제외했습니다.

## 실행 검증 범위

- 실제 나래3가 가상 한울반 현장체험학습 계획서 HWP를 작성하고, 나래한글 엔진으로 본문을 다시 읽었습니다. 2026-11-13 09:30~12:00, 가상 생태체험관, 가상 학생 5명·인솔 2명, 가상 예산 120,000원입니다. 문서에 훈련용·실제 일정 아님을 표시했습니다.
- 실제 나래3의 PDF 출력 도구 호출과 한컴 출력 결과를 확인했습니다. 생성된 한 페이지 PDF를 렌더링해 읽을 수 있는지 검수했습니다.
- 일부 반복 시험은 파일 저장 후 마지막 설명 생성에서 시간 초과가 났습니다. 실제 생성·재읽기·출력 도구 기록과 현재 파일 해시를 대조하고, 수정된 제어기의 검증 완료 응답을 확인했습니다. 이를 단일 대화의 완전 자율 성공률로 집계하지 않습니다.
- 격리된 합성 나이스 브라우저에서 조퇴 값 입력·결재선 지정과 미상신 준비를 확인했습니다. 별도의 준비된 합성 신청에서는 네이티브 확인창을 거친 1회 상신과 결과 목록 조회를 확인했습니다.
- 모의 CBE에서 받은 쪽지 3건과 대화 3건을 각각 모두 읽은 뒤 요약했습니다. 모의 정상 발송은 수신자 검색 뒤 1회 실행했고, 결과 미확인 발송은 반복하지 않았습니다.
- WXS 모의 첨부는 실제 나래3 생성 HWP를 복사하고 원본·모의 서버 사본 SHA256을 대조합니다. 이는 실제 학교 WXS의 파일 선택·업로드·결재를 검증한 결과가 아닙니다.
- 자료 대조를 보강한 재시험에서 실제 계획서를 먼저 읽고 같은 일자·장소·인원·예산의 기안 본문을 작성했습니다. 모의 WXS 도구 9단계로 첨부 해시 대조·상신 시도 1회·확인 1회·결과 목록 조회 1회를 확인했습니다. 결과 미확인 발송도 다시 시험해 전송 여부를 단정하지 않는 응답과 재전송 없음이 확인됐습니다.
- 실제 CBE 받은 쪽지 5건은 기존 나래3 v1이 목록 1회와 본문 5회 조회 후 요약했습니다. 개인 본문과 요약은 공개하거나 학습에 사용하지 않았습니다. 가상 문서·모의 업무 시험은 추가 학습 후보 v2를 사용했습니다.

실제 학교 시스템에 훈련용 기안을 상신하거나 이 검증을 위해 실제 메시지를 새로 발송하지 않았습니다.

## 발견한 오류와 실행 제어 보강

- PDF 도구 호출 없이 PDF가 생성됐다고 답했습니다. 새 문서와 PDF를 함께 요청하면 실제 생성·재읽기·PDF 출력이 필요하도록 바꾸고, 검증된 저장 결과로 완료를 알립니다. 출력 실패를 성공으로 표시하지 않습니다.
- 한글 조회 결과의 반복된 문단 서식을 사전과 참조로 묶었습니다. 원문·문단 ID·해시·서식 값은 보존하며 모델 입력의 중복을 줄입니다.
- 생성 문서의 실제 조회 JSON은 12,313자에서 3,873자로 줄었습니다. 이는 해당 결과의 직렬화 길이이며 모델의 전체 RAM 사용량이나 보편적인 속도 향상률을 의미하지 않습니다.
- 모의 기안 본문에 첨부에 없는 2025년 일정을 작성했습니다. 첨부를 실제로 읽게 하고, 첨부·사용자 요청에서 확인되지 않은 날짜는 입력 전에 차단합니다. 이 검사는 모든 종류의 사실 오류를 탐지하는 기능은 아닙니다.
- WXS의 관찰한 HWND·현재 제목·같은 실행의 receiptId·실제 확인창 문구를 다음 도구 인자에 연결합니다. 실제 CLI의 `present` / `message` 형태를 처리합니다. 내부결재 추가 검토·인증·서명·예상 밖 확인창을 일반 확인으로 자동 수락하지 않습니다.
- 잘못된 모델 인자는 실행 전에 차단하고 오류 필드를 모델에 돌려줍니다. 메시지 전송 결과가 불명확하면 성공이나 실패로 단정하지 않고 미확인 상태와 재전송하지 않았음을 알립니다.
- 달력은 실제 월·날짜 표시가 갱신된 뒤 관찰 결과를 반환합니다. 로컬 AI의 추가 RAM 프롬프트 캐시는 끄고 배치를 512/128로 지정합니다.

위 실행 제어가 있는 제한된 합성 시험과, 새로운 실제 학교 화면에서의 자율 업무 성공은 다릅니다. 원본 실패 기록을 유지했으며 검증·시험 결과를 본 뒤 후보 가중치를 다시 조정하지 않았습니다.
