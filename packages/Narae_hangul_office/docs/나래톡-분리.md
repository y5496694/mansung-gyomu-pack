# 나래톡과 나래 한글 오피스

[나래톡](https://github.com/y5496694/Narae_talk)은 나래 시리즈를 사용하여 교육 업무를 포함한 다양한 업무를 도와주는 에이전트입니다. [나래 한글 오피스](https://github.com/y5496694/Narae_hangul_office)는 문서 전용 앱입니다.

나래톡은 에이전트 앱, 나래 한글 오피스는 한글 문서 앱입니다. 같은 소스 배포본에서 각각 설치할 수 있으며 창·트레이·아이콘·프로필·대화·설정 저장소가 분리됩니다.

| 기능 | 나래톡 | 나래 한글 오피스 |
| --- | --- | --- |
| 친구별 CLI 대화, 독립 대화창 | 지원 | 없음 |
| 기본 친구 나래의 전체 도구 사용 | 지원 | 없음 |
| 첫 실행 이름, 선택 직업·지역 | 지원 | 없음 |
| AI OAuth/API, 로컬 모델 설치 | 지원 | 문서 AI용 지원 |
| 메신저·인증서·브라우저·예약 | 지원 | 없음 |
| HWP/HWPX 읽기·작성·편집·PDF | 나래한글 친구 | 지원 |

## 실행과 설치

- 개발: `npm start` / `npm run start:talk`
- 나래톡 설치: `나래톡 설치.cmd` 또는 `powershell -File scripts/install.ps1 -Product Talk`
- 오피스 설치: `설치.cmd` 또는 `powershell -File scripts/install.ps1 -Product Office`
- 나래톡 실행: 바탕화면 **나래톡** 또는 `나래톡 실행.cmd`
- CLI: 문서는 `narae-office`, 에이전트는 `narae-talk`

기본 설치는 D 드라이브가 있으면 `D:\Codex\apps\NaraeTalk`, `D:\Codex\apps\NaraeHangulOffice`를 사용합니다. 나래톡 데이터는 `D:\Codex\narae-data\NaraeTalk`, 환경변수 `NARAE_TALK_HOME`으로 별도 지정할 수 있습니다. D 드라이브가 없는 PC는 Windows 로컬 앱 폴더를 사용합니다.

## 친구와 대화

기본 친구 **나래**는 현재 설치된 통합 도구를 모두 사용할 수 있습니다. **나래한글**, **충북소통메신저**, **나래 브라우저**, **나래교무 포탈(지역명)**, **카카오톡**은 해당 도구만 사용합니다. 나이스·에듀파인·WXS는 지역 포탈 친구 하나에 통합하며 WXS·나래교무 개별 친구를 중복 표시하지 않습니다. 교육청을 바꾸면 지원되는 지역 메신저 친구가 나타납니다. 카카오톡 친구는 PC 카카오톡 CLI를 사용하며 원격 챗봇 연동과 별개입니다.

친구·채팅·설정 창은 모두 394×715를 기본 크기로 사용하며, 창 크기를 조절하면 목록과 대화가 반응형으로 배치됩니다. 제목줄 30px, 왼쪽 탐색 막대 66px, 친구 행 72px, 메시지 입력 영역 약 116px를 기준으로 구성했습니다.

친구를 선택하면 선택 상태가 표시됩니다. 더블클릭 또는 오른쪽 위 ↗로 독립 대화창을 엽니다. Enter는 전송, Shift+Enter는 줄바꿈, Esc는 현재 독립 대화창 닫기입니다. 친구별·원격 사용자별 대화와 모델 입력 이력을 분리합니다. 도구 제한은 AI에 제공하는 목록과 실제 실행 단계에 각각 적용합니다.

충북소통메신저와 카카오톡의 아이콘은 설치 프로그램의 원본 아이콘입니다. 나래톡의 앱 아이콘과 나래 친구 아이콘은 첨부된 나래 로고의 남색·네 꽃잎 색상을 기준으로 만든 SVG 자산입니다.

## 친구 추가

목록 오른쪽 위 친구 추가에서 이지에듀·하이클래스·나래 무비 메이커를 선택합니다. 로딩 창에 “친구를 추가하고 있습니다.”와 다운로드 진행률을 표시하고, GitHub 원본 또는 공식 CLI 배포본의 SHA-256·필수 파일·CLI 실행 준비를 확인한 뒤 등록합니다. 취소·실패한 설치는 친구 목록에 넣지 않습니다. 설치 기록과 기능 파일은 나래톡 데이터의 `data/talk-addons.json`, `addons`에 보관합니다.

이지에듀는 일정 CLI, 하이클래스는 브라우저 작업 스킬, 무비 메이커는 독립 CLI입니다. 추가된 기능은 나래 친구도 사용할 수 있으며 개별 친구의 도구 범위는 해당 기능으로 제한합니다. 동영상·음성·자막·프로젝트 파일도 대화에 첨부할 수 있습니다.

## 설정과 기존 데이터

첫 실행에 이름을 입력하고 직업과 지역을 선택 목록에서 고릅니다. 직업·지역은 생략할 수 있으며 설정 → 일반에서 수정합니다. 직업은 교사·교육행정직·교육공무직·회사원·자영업·프리랜서·학생·기타, 지역은 17개 시도 중 선택합니다.

**교사 + 충북**을 선택·저장하면 나래교무 포탈(충북)과 충북소통메신저 친구가 자동으로 나타납니다. 실제 업무포털 설정도 충북 `cbe.eduptl.kr`로 맞춰집니다. 지역을 바꾸면 해당 교육청의 포털과 메신저 친구로 갱신되며, 학교 업무 직업이나 지역을 생략하면 기본 친구만 표시합니다. 기존 대화는 지우지 않고 학교 업무 친구의 지역별 이력을 구분합니다. 설정의 업무 지역은 프로필과 자동 동기화됩니다. 이는 로컬 프로필이며 원격 서비스 계정 가입이 아닙니다.

설정에서 일반·인증서·AI 연결·메신저·예약 작업·사용 안내를 엽니다. AI 연결에서는 나래1~4 모델 설치, 해시 확인, 기존 모델 가져오기, 실행·중지, 외부 로컬 서버, GPT·Claude 연결을 사용합니다. 기존 모델의 가중치를 다시 학습한 것으로 표시하지 않습니다.

기존 오피스의 AI·교육청·브라우저 설정 및 암호화된 자격 정보는 첫 실행에 한 번 복사하며 원본은 보존합니다. 모델은 기존 파일 위치를 재사용해 중복 다운로드하지 않습니다. 메신저의 원격 연결과 예약은 이전 앱을 종료한 뒤 설치 갱신의 인계 단계에서 옮겨야 합니다. 두 앱이 같은 봇을 동시에 폴링하지 않게 하기 위한 구분입니다.

도구 실행 승인, 실제 전송 결과 확인, 공문 상신·결재의 명시적 요청과 서버 재조회 등 기존 실행기의 조건을 유지합니다. 실제 학교 서비스 로그인·발송·기안은 UI 변경 시험에 포함하지 않습니다.

## 확인

`npm test`는 문서·통합 실행기의 회귀 검사를 수행합니다. `npm run test:talk:desktop`은 별도 데이터와 루프백 AI 서버로 첫 실행, 친구 검색, 도구 범위, 대화 분리·복원, 독립 창, 설정, 오피스의 에이전트 IPC 차단을 실제 Electron에서 확인합니다. 모델 다운로드는 기존 다운로드·해시 검사 테스트를 사용하며 실제 모델을 다시 내려받는 시험은 하지 않습니다.
