- ChatGPT OAuth를 기본값으로 제공하며 OpenAI API·Claude Console OAuth·Claude API를 함께 지원합니다.
- 실제 한글 본문·문단 서식 편집, 나래한글 엔진의 문서 생성·파일 편집, 한글 PDF 미리보기와 사본 출력을 제공합니다.
- 사용자별 설치와 전용 Python 환경, Windows 암호화 자격 증명 저장을 지원합니다.
- **한컴오피스 한글만 사전 설치**하면 나머지 Node.js·Python·Electron·엔진 라이브러리·Claude 로그인 도구는 `설치.cmd` 한 번으로 자동 설치합니다. 시스템의 Node.js·Python·PATH를 바꾸지 않습니다.
- 한컴 2024 전용 경로를 제거하고 설치된 여러 한글 버전을 탐색합니다. **2022와 2024에서 실제 HWP/HWPX 편집·저장·재열기·PDF를 검증**했습니다. 다른 Windows 버전은 자동 탐색 대상이며 실제 기능 호환성은 미검증입니다.

`Narae-Hangul-Office-0.9.0-windows-x64.zip`을 내려받아 압축을 풀고 **설치.cmd**를 실행하세요. Windows 10/11 x64와 한컴오피스 한글이 필요합니다. 첫 설치는 인터넷에 연결되어 있어야 합니다. Node.js나 Python을 별도로 설치하지 않아도 됩니다.

Claude Console OAuth는 Pro/Max 구독과 별개의 API 사용량 과금입니다. 실제 계정 로그인은 사용자가 앱 설정에서 승인합니다.
