## 기본 설정에서 발견한 문제와 재시험

첫 실행은 이미지 7건 중 엄격한 JSON 항목 기준으로 2건만 통과했습니다. 문서·문서 사진·스캔 PDF의 주요 값은 읽었지만 요청한 영문 항목명 대신 한글 항목명을 쓰는 경우가 있었고, 로고에서는 1,024 출력 토큰을 추론에 소진해 최종 답변을 못 냈습니다. 원본 실패 기록은 유지했습니다.

두 번째 실행은 다음과 같이 바꿨습니다.

- JSON Schema로 **항목 이름·자료형만** 지정했습니다. 정답 값이나 정답 후보는 전달하지 않았습니다.
- 추론 토큰을 256개로 제한했습니다. 이미지 총 출력 한도는 1,024개, 업무 행동 선택 총 출력 한도는 512개입니다.
- 기존 이미지 7건을 재사용하고, 별도의 새 한국어 안내문 1건을 추가했습니다.

**두 번째 실행은 첫 결과를 보고 설정을 조정한 재시험이므로 맹검 성능 평가가 아닙니다.** 가중치 학습과 구분합니다. 특수 글꼴 로고 오독도 실패로 남겼습니다.

1. **나래4 후보로 유지합니다.** 먼저 사진·PDF 읽기 도구에 LFM3-VL을 연결하고, 결과·근거 페이지를 기존 문서·업무 에이전트에 전달하는 방향이 적합합니다.
2. 텍스트 PDF는 기존 글자 추출을 먼저 사용하고, 스캔·그림·그래프는 이미지 분석을 선택하도록 구성할 수 있습니다. 같은 자료의 Windows 한국어 OCR은 약 1초에 글자를 추출했지만 시간의 콜론·일부 글자·금액 오독이 있었습니다. 이는 모델의 구조화된 내용 이해와 다른 기능입니다.
