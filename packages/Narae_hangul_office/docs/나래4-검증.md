# 나래4 학습 및 실행 검증 — 2026-10-31

나래 한글 오피스 `0.13.0-preview.17`에 `Narae4-Qwen3.5-2B-Office-LoRA-v1`을 추가했습니다. Qwen3.5-2B의 Office LoRA를 실제로 학습했으며, LiquidAI/d1-2B는 사전학습된 선택형 판단기로 연결했습니다. 시각 인코더와 d1 가중치는 이번에 학습하지 않았습니다. 두 모델을 공동 학습한 sparse MoE는 아닙니다.

| 평가 | 결과 | 해석 |

| 설치된 Electron 앱 | 에이전트 탭에서 HWPX 생성 후 내용 재검사 통과 | 테스트 전용 데이터 폴더, 전체 통합 도구 목록 사용 |

다음 행동 평가의 미통과 사례는 변경 추적 문서를 실제로 읽는 대신 읽겠다는 답만 한 경우입니다. 앱에서 `textDetailsLoaded:false`를 관찰하면 실제 `read_live_document`가 먼저 실행되도록 보완했습니다. 이는 모델 가중치의 개선과 구분합니다. 정답 판정에서 스키마상 동등한 편집과 사실에 맞는 미저장 보고를 인정하도록 학습 전에 양쪽 평가에 같은 기준을 적용했습니다.

실제 작업 시험 중 `type:text`라는 잘못된 블록, 일반 파일에 대한 잘못된 live 편집, 반복 읽기, PDF 리소스 정리 오류를 확인했습니다. 도구 계약과 저장 파일 읽기→편집→재읽기 흐름을 고치고, 일반 본문 생성은 `text` 인자를 사용하게 했습니다. PDF는 `pypdfium2` 객체를 명시적으로 닫도록 수정한 뒤 실제 출력·추출·렌더링을 확인했습니다. 최종 합성 작업 3/3은 이 앱 수정이 포함된 결과입니다.

이미지 시험은 가상의 안내 그림에서 장소·시작/종료 시각·금액을 읽고, 없는 전화번호를 추측하지 않는지 확인했습니다. 생성 문서의 기본 동작은 통과했지만 불필요한 자리표시자가 포함된 사례도 있어, 완성된 공문 품질이나 모든 업무의 자율 처리 성공을 보장하는 평가는 아닙니다.

## 실행 비용

모델 파일 네 개의 합계는 3,051,250,400바이트입니다. 실제 판단기와 텍스트 본체를 함께 실행한 시험의 두 프로세스 RSS 합계는 3,954,315,264바이트, 약 3.68GiB였습니다. 이미지 분석 때 판단기를 종료한 뒤 본체 프로세스의 최대 RSS는 2,909,204,480바이트, 약 2.71GiB였습니다. 앱·운영체제 메모리는 별도입니다.

본체를 준비한 뒤 판단기의 콜드 시작을 포함한 첫 선택은 5.088초, 이미 켜진 판단기의 다음 선택은 0.922초였습니다. 설치된 앱의 전체 도구 목록을 포함한 문서 생성 요청에서는 본체 프롬프트 처리 약 32.9초, 생성 약 9.1초를 기록했습니다. 작업 종류·문맥·다른 프로세스 부하에 따라 시간이 달라집니다. 본체 요청 전체가 1초 안에 끝난다는 의미가 아닙니다.

## 실제 에듀파인과 데이터 구분

사용자가 허용한 기존 Chrome과 나래 브라우저 연결로 실제 업무포털 인증 및 K-에듀파인 진입을 확인했습니다. 문서등록대장 목록 자동 조회는 완료하지 못했습니다. 현재 메뉴 관찰 뒤 요청한 목록까지 도달하지 못한 상태로, 실행 결과 JSON에도 미검증으로 기록합니다. 인증·진입과 목록 조회 성공을 같은 결과로 계산하지 않습니다. 실제 공문 작성·수정·상신·공람확인·발송은 시험하지 않았습니다.

실제 화면의 공지창과 관찰한 메뉴로 진행하도록 앱 절차를 보완했습니다. 이미 읽은 절차를 처음부터 반복하지 않고 남은 offset을 이어 읽게 했으며, 요청 목록에 도착하기 전에 조회 완료라고 답하지 않게 했습니다. 이 수정은 실제 UI에서 드러난 앱 문제에 대한 보완입니다.

학습·검증·홀드아웃에는 실제 학교 문서, 학생 정보, 메시지, 인증정보를 넣지 않았습니다. 실제 포털 세션·화면 자료·로그인 도우미는 재현 폴더 및 배포 자료에서 제외합니다. 원본 모델과 판단기의 이용조건은 별도 라이선스를 따릅니다.

## 설치와 재현

이 PC에는 앱 `D:\Codex\apps\NaraeHangulOffice`, 모델 `D:\Codex\models\narae-office\narae4`에 설치했습니다. 설정 → AI 연결 → 로컬 AI에서 나래4를 사용할 수 있습니다. 공통 추천 모델 표시는 기존 나래3으로 유지하며, 사용자 요청에 따라 이 PC의 선택만 별도로 바꿀 수 있습니다. 원래 모델은 보존합니다.
