# 나래 카카오톡 ↔ 오피스 에이전트(실험)

## 구성

나래 한글 오피스가 PC 실행기입니다. 상단 **한글 문서**는 기존 문서 작업 공간이고, **에이전트(실험)**는 CBE_CLI·나래 브라우저·나래교무 포탈·나래교무를 사용하는 통합 대화 공간입니다. 공식 나래 채널과 연결한 후에는 에이전트 탭과 카톡이 같은 사용자별 대화 문맥을 사용합니다. 일반 문서 탭의 대화는 카톡에 공유하지 않습니다.

- 채널: **나래**, 검색 ID **narae_bot**
- 채널 주소: https://pf.kakao.com/_xjgxfWX
- 채팅 주소: https://pf.kakao.com/_xjgxfWX/chat
- 공식 채널 챗봇 스킬만 사용합니다. 비공식 개인 카카오 로그인·LOCO 연결은 없습니다.
- 오피스에서 선택한 AI를 사용하며 교무용 대형 로컬 모델을 자동 설치·기동하지 않습니다.
- 계정별 승인 PC 한 대를 지원합니다. 다른 카톡 계정은 자기 PC에 별도로 연결합니다.

## 사용 순서

1. 나래 채널에 `내 UID`를 보냅니다. UID는 식별자이지 비밀번호가 아닙니다.
2. 오피스 상단 **카카오톡 연동**에서 운영자가 알려 준 HTTPS 중계 기본 주소와 UID·PC 이름을 입력하고 데이터 경유·업무 권한에 동의합니다.
3. **UID로 연결 요청**을 누르고 PC 화면의 `연결 <코드>`를 같은 카톡 계정에서 보냅니다. 코드는 5분 이내 한 번만 쓸 수 있습니다.
4. PC에서 새로고침 후 **이 카톡 사용자의 PC 연결 승인**을 누릅니다. UID만 아는 다른 사람이 PC를 신청해도 카톡 계정 확인을 통과할 수 없습니다.
5. **에이전트(실험)** 탭 또는 카톡에서 업무를 요청합니다. 문서 변경·브라우저 조작·CBE 발송·WXS 저장 등은 구체적인 미리보기를 PC에서 일회 승인해야 실행됩니다. 거절·중단·만료는 승인이 아닙니다.
6. 카톡의 `대화 확인`으로 공유된 최근 대화를 조회하고 후속 요청으로 이어갈 수 있습니다. `결과 확인`, `연결 상태`, `중단`, `연결 해제`도 지원합니다.

연결 전 PC 대화는 로컬 전용입니다. 연결 승인 후에는 해당 사용자·기기 연결 ID의 대화로 전환하며 연결 전 대화를 자동으로 다른 카톡 계정에 업로드하지 않습니다. 최근 100개 메시지를 PC에 저장하고, AI에 넣는 문맥은 엔진의 최근 대화 범위를 따릅니다. 카톡 조회용 서버에는 최근 20개 메시지를 각각 800자까지 공유합니다. **PC에서 쓴 새 메시지를 카톡에 임의 선제 발송하는 기능은 없습니다.** 카톡에서 조회하거나 후속 요청을 보냅니다.

## 포함된 업무 도구

검증된 나래교무 소스와 구성요소를 `vendor/narae-gyomu`에 포함합니다. `OFFICE_VENDOR_LOCK.json`과 upstream `sources.lock.json`의 SHA256을 자동 검사합니다. 외부 저장소가 바뀌어도 설치할 때 임의 최신 코드를 가져오지 않습니다.

- **CBE_CLI:** 충북소통메신저 상태·사람 검색·쪽지/대화 조회, 발송 미리보기와 PC 승인 후 실행. 해당 PC의 메신저가 로그인되어 있고 로컬 연결이 준비되어야 합니다.
- **나래 브라우저:** 독립된 실제 브라우저 관찰·본문 읽기·탭/프레임 이동, 승인한 열기·클릭·일반 입력. 비밀번호·일회성 인증 입력과 임의 키 입력은 차단합니다. 인증서·학교 로그인은 사용자가 PC에서 직접 진행합니다.
- **나래교무 포탈:** 포털 열기·WXS 처리 도구와 업무 절차를 포함합니다. 학교 로그인·실제 공문 상신 성공을 보장하지 않습니다. 저장/변경의 미리보기와 실제 실행을 구분합니다.
- **나래교무:** 위 도구의 업무 스킬·순서와 통합 도구를 현재 오피스 AI가 사용합니다. 별도 로컬 모델을 실행하지 않습니다.
- **한글:** 기존 나래한글 엔진과 한컴 연동을 재사용합니다. 한컴 전용 편집·PDF 출력에는 설치된 한컴오피스 한글이 필요합니다.

이지에듀·하이클래스 등 실제 학교 업무의 전체 연동, 여러 PC 선택, 카톡 파일 업로드·파일 첨부 전송은 이 버전의 보장 범위가 아닙니다. 결과 문서는 해당 PC 작업 폴더에 남습니다.

## 중계 서버와 챗봇 설정

Node.js 24 이상에서 전용 데이터 디렉터리와 HTTPS 주소를 사용합니다. 개발용 임시 터널은 프로세스·주소가 바뀔 수 있어 상시 운영 서비스가 아닙니다.

```powershell
$env:NARAE_RELAY_HOME = "$env:LOCALAPPDATA\NaraeKakaoRelay"
$env:NARAE_KAKAO_BOT_ID = "공식 챗봇 payload의 실제 bot.id"
$env:NARAE_RELAY_PORT = "8941"
npm run relay:kakao
```

PC는 HTTPS 서버로 아웃바운드 연결하며 PC 인바운드 포트를 열지 않습니다. 중계 서버는 기본 `127.0.0.1:8941`에 바인딩합니다. TLS 역방향 프록시에서 필요한 경로만 공개하세요.

첫 실행에 중계 데이터 디렉터리의 `skill-secret.txt`와 `relay.json`이 생성됩니다. 챗봇 관리자센터에서 **나래 봇**의 스킬 URL을 `https://중계주소/kakao/<비밀 키>`로 설정하고 폴백 블록과 필요한 발화 블록에서 해당 스킬 응답을 사용하도록 배포합니다. 비밀 스킬 URL은 관리자 설정에만 사용하고 Git·공개 문서·스크린샷·일반 로그에 넣지 않습니다. 사용자에게는 HTTPS 기본 주소만 알려 줍니다. 채널 검색 ID는 `bot.id`와 다른 값입니다. 실제 나래 봇의 ID를 확인한 후 제한을 설정합니다. 와니 채널 설정은 변경하지 않습니다.

`/health`는 공개 상태 확인, `/v1/pairings`는 미승인 신청, `/v1/device/*`는 기기별 Bearer 인증 경로입니다. 공개 관리자 API·임의 셸·페이지 JavaScript 실행 API는 없습니다. 단일 서버 프로세스가 JSON 상태 파일을 소유하는 미리보기 구조입니다. 대규모 운영에는 DB 트랜잭션·잠금·보존/삭제 정책이 추가로 필요합니다.

## 데이터·안전·장시간 작업

- 기기 토큰·AI 자격은 Windows 사용자 DPAPI로 보관하고 토큰을 화면에 노출하지 않습니다.
- 요청·답변·AI에 사용한 문서/조회 내용은 카카오·중계 서버·선택한 AI 제공자를 경유할 수 있습니다. 중계 운영자는 서버 저장 내용에 접근할 수 있습니다.
- 요청·결과·조회용 공유 대화는 서버에 최대 7일 보관합니다. 연결 해제 시 공유 대화 사본과 기기 권한을 폐기하지만 기존 작업 기록 전체 삭제를 의미하지는 않습니다. 운영자는 백업·개인정보 삭제 정책을 따로 마련해야 합니다.
- 승인·이력은 기기별로 분리합니다. 연결 해제·서버 권한 취소는 진행 작업을 중단하고 이전 사용자의 브라우저·임시 도구 권한을 정리합니다. 이미 수행한 작업은 되돌리지 않습니다.
- 작업 폴더 탈출·symlink/junction 우회·임의 셸·미선언 인자는 차단합니다. 파일 덮어쓰기·편집에는 엔진의 추가 보호가 적용됩니다.
- PC가 꺼져 있거나 완료가 불확실한 요청을 나중에 자동 재실행하지 않습니다.
- 카톡 콜백은 일회성이고 약 5분의 유효 시간이 있습니다. 긴 작업은 만료 전에 **결과 확인 버튼**을 전달하고 최종 결과는 서버에 보존해 조회합니다. 같은 콜백으로 진행 안내와 최종 답변을 두 번 보내지는 않습니다.
- HTTPS `bot-api.kakao.com`의 정확한 호스트만 허용하며 리다이렉트를 따르지 않습니다. HTTP 200도 JSON `status: SUCCESS`가 아니면 성공이 아닙니다. 접수 성공과 사용자 휴대폰 도착은 다른 증거입니다. 만료·거부·불확실한 발송을 자동 반복하지 않습니다.
- 요청은 4,000자, 결과는 최대 12,000자를 보관하고 긴 답변을 페이지로 나눕니다.

## 검증 범위

```powershell
npm ci
# 전용 Python에 requirements.txt 준비
npm test
npm run test:kakao:desktop
npm run package
```

단위·보안 회귀 외에 실제 Electron·DPAPI·나래 CLI/HWPX·실제 나래 브라우저를 사용합니다. 에이전트 탭과 카톡 공통 문맥, 일반 문서 대화 격리, 승인 전 쓰기 차단, 승인 후 저장·재조회, 거절 후 미생성, 브라우저 승인·본문 읽기, 비밀번호/OTP 입력 차단, 재시작 후 연결·대화 유지, 해제 후 이전 사용자 대화 숨김을 검증합니다.

카카오 payload와 AI 응답은 모의입니다. 이 검사만으로 실제 나래 채널 왕복, 실제 AI 과금·응답, 학교 로그인·CBE 발송·공문 상신을 성공했다고 주장하지 않습니다. 실제 사용자 기기의 송수신은 별도 확인이 필요합니다. `NARAE_KAKAO_ALLOW_LOOPBACK=1`은 합성 로컬 테스트에만 사용합니다.
