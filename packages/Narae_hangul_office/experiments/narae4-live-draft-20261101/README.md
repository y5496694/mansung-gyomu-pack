# 실제 기안·상신·회수·삭제 검증과 로그인 복구

2026-11-01. 사용자가 별도 시험 기안의 실제 상신·회수·수정·정리와 로컬 보안정보 자동 로그인을 명시적으로 맡긴 작업이다. 기존 업무 문서를 시험용으로 재사용하지 않는다.

## 변경

- 현재 인증서 로그인 화면을 예전 메인 탭으로 대체하지 않는다. 다른 탭을 확인한 뒤에는 원래 탭의 참조를 다시 읽는다.
- 시스템과 이름이 같은 알림 분류 링크를 서비스 진입 버튼으로 선택하지 않는다. 명시한 포털 URL과 다른 경로의 복원 탭을 혼동하지 않는다.
- 맡긴 로컬 인증서 프로그램 연결은 해당 HTTPS 업무 사이트 한 곳에만 허용한다. 브라우저 전체 보안 옵션을 끄지 않는다. 진단에는 권한·로딩·네트워크 오류 분류만 반환하고 비밀 인자는 반환하지 않는다.
- 포털 인증과 서비스 진입 결과를 구분하고, 실제 화면의 HTTP 오류를 따로 보고한다. 인증서 제출 후 결과 불명 시 중복 제출하지 않는다.
- WXS 본문 PNG·전체 HWP 사본·서버 첨부를 실제 네이티브 CLI로 새 검수 경로에 저장한다.
- 회수·회수본 삭제는 정확한 제목·실제 문서 ID·선택 한 행·상태·화면 지문·실제 확인 문구를 대조한다. 일반 삭제는 계속 차단한다. 후속 의견작성 창이나 서버 재조회가 남으면 미완료다.
- 이미 열린 사이트 안내창은 새 snapshot에서도 같은 확인창으로 관찰한다.
- 빈 공용 표준 기안의 로컬 첨부 바이트 등록을 원본 CLI에서 보완했다. 기존 문서·다른 앱에는 적용하지 않으며 네이티브 등록이 있는 앱으로 전환되면 중복 등록하지 않는다.
- 현재 WXS 입력·저장은 웹 탐색부터 재시작하지 않는다. 명시한 본문·첨부·결재선·공개 설정에 입력을 묶고, 일부 입력 실패와 성공한 저장 뒤에는 실제 상태를 재조회해 반복을 막는다.
- 기존 결재선 확인과 같은 상신 기록의 재개, 문서처리 뒤 원문공개 주의 확인을 원본 CLI에 연결했다. 사전검사 거절과 결과 불명 시도를 구분하고 기존 잠금을 유지한다.
- 실제 의견작성 창은 같은 출처의 opener 목록에서 선택된 정확한 제목·문서 ID·회수 상태와 대조한다. 지정된 사유만 입력하고 부모 프레임으로 돌아가 다시 조회한다.
- 목록의 빈 상태 아이콘 열과 실제 진행상태 열을 구분하고, 체크박스 안의 서식 ID를 문서 ID로 오인하지 않는다. 자동 새로고침 뒤에는 오래된 ref를 반복하지 않는다.

## 검증 범위

최종 Office 코드 회귀시험 **305/305**, 원본 포털 Python 시험 **97/97**, 네이티브 JS 액션 시험 **26/26**, 공통 CLI 시험 **19/19**가 통과했다. 실패·생략은 없다. 공통 원본 4개·541개 파일과 Office 동결 공급본 563개 파일의 검증을 유지한다. [시험 집계](results/regression.json)에 범위를 기록했다. 로컬 권한의 다른 출처·HTTP·출처 변경·개인 브라우저 거절, 확인창 재관찰, 기존 문서·결재선·첨부와 중복 처리 거절을 포함한다.

실제 로컬 나래4 v1과 Office 통합 도구로 등록 DPAPI 문서의 업무포털 인증을 확인했다. 에듀파인 SSO 오류는 실제 문서작성 진입 메뉴로 복구했고 로컬 보안 프로그램 및 등록 WXS 실행기의 연결을 확인했다. 브라우저 전체 보안을 해제하지 않았다.

별도 시험 기안 한 건에서 다음을 실제 확인했다.

| 단계 | 실제 결과 | 수행·검증 범위 |
| --- | --- | --- |
| 기안 입력·임시저장 | 제목·본문·기존 과제·공개·결재선·한글 첨부 1건 저장 | 나래4가 입력·저장. 저장 뒤 불필요한 반복 조회를 중단하도록 제어기를 보완 |
| 본문 검수 | 1쪽 캡처, 본문 전체 돋움체 12pt, 끝맺음과 표준 필드 확인 | Codex가 네이티브 출력과 한글 CLI로 검수 |
| 임시저장 서버 사본 | 실제 목록에서 재열기, 첨부 원본 SHA-256 일치 | Codex가 새 다운로드의 바이트를 대조 |
| 실제 상신 | 서버 문서진행에 같은 기안과 다음 검토자 표시 | 나래4가 최종 실행을 시작. 결재선 재확인·같은 기록 재개·원문공개 확인은 Codex가 이어 처리 |
| 상신 서버 사본 | 실제 기안 완료 이력, 본문·공개·결재선 유지, 첨부 SHA-256 일치 | Codex가 읽기 전용 서버 사본을 내려받아 검수 후 닫음 |
| 회수 | 의견 입력·확인 후 서버의 같은 문서가 회수 상태 | 나래4가 실제 회수와 의견 처리. 자동 새로고침 후 Codex가 서버 재조회 |
| 회수본 삭제 | 실제 삭제 안내, 정확한 제목의 서버 재조회 0건 | 나래4가 실제 삭제와 의견 처리·재조회. 의견창부터 이어간 조회 범위 판정 오류를 보완하고 Codex가 부재 재확인 |

기존 진행 업무 문서 두 건은 유지되었다. 시험 기안의 임시저장 검수 사본과 로컬 증거 파일은 남겨 두었다. 변경·재상신 전체 흐름은 이번 실환경 검증 범위에 포함하지 않는다. 결재선 재확인 제어기와 원문공개 확인 제어기의 새 연결은 합성 회귀시험 범위도 함께 표시한다.

이 결과는 **Codex가 복구와 검수를 보조한 실환경 흐름**이다. 나래4 단독의 처음부터 끝까지 자율 성공이나 필수 10과제 전체 실환경 통과로 판정하지 않는다. 실제 기록·보안 문서·학교 화면·개인 식별값은 비공개 로컬 작업 폴더에만 보관하며 공개 저장소에는 넣지 않는다.

가중치를 추가 학습하거나 v1 어댑터를 교체한 작업이 아니다. 기존 합성 필수 과제 9/10과 실제 업무 성공을 구분한다.

```powershell
node --test --test-concurrency=1 tests/*.test.cjs
node --test --test-concurrency=1 tests/portal-browser.test.cjs tests/portal-integration.test.cjs
```
