# 나래4 단독 기안 재검증: 미통과

2026-11-01. 실제 로컬 `Narae4-Qwen3.5-2B-Office-LoRA-v1`, 실제 충북 업무포털·K-에듀파인·등록 WXS 기안기를 사용했다. 합성 웹 서버나 클라우드 모델로 대체하지 않았다. 요청은 별도의 시험 기안 한 건을 작성·검수·임시저장·상신·서버 확인·회수·삭제하는 것이었다. 기존 업무 문서와 열린 원본 WXS는 보존했다.

각 시행 중 실행기 소스는 바꾸지 않았으며 시작·종료 SHA-256을 대조했다. 실행이 중단된 뒤의 Codex 진단·수정은 다음 시행과 구분했다. 아래의 부분 성공을 합쳐 단독 전체 성공으로 판정하지 않는다.

| 시행 | 나래4가 수행한 실제 단계 | 중단 지점 |
| --- | --- | --- |
| r11 | 첨부 원문 읽기, 등록 보안정보 로그인, 에듀파인 진입 | 늦은 공지가 메뉴 클릭을 막은 후 메뉴를 이미 연 것으로 기록; 상태 조회 반복 |
| r12 | 원문 읽기·로그인·과제카드·결재선·본문·공개 설정·한글 첨부·본문 사본 서식 읽기·실제 캡처·실제 시각 모델 검수·서버 임시저장 | 임시저장 목록 메뉴로의 전환 미확인. 상신하지 않음 |
| r13 | 원문 읽기·로그인·실제 표준서식·기존 창 보존·과제카드 선택 시도 | 과제 선택창이 닫힐 때 COM 응답 읽기가 거부됨. 중단 후 별도 조회로 선택 반영을 확인했으나 같은 실행의 성공으로 복구하지 않음 |
| r14 | 원문 읽기·로그인·에듀파인 진입·등록 기안기 실행 | 새 기안의 시작 상태 조회에서 SendMessageTimeout. 저장·상신·회수·삭제 없음 |

r12의 실제 캡처는 1쪽이며 `read_image` 뒤 실제 이미지 입력 요청 1회와 시각 검수 기록이 있다. 임시저장은 원본 CLI의 성공 안내를 받았다. 서버 임시저장 사본의 재열람·첨부 바이트 대조부터는 이 시행에서 완료하지 못했다. 임시저장 검수본과 로컬 증거는 유지한다.

실제 오류에 따라 다음을 보완했다. 실패한 메뉴 클릭을 성공으로 기록하지 않고, 실제 Nexacro 트리 메뉴에는 지원되는 DOM 이벤트를 적용한다. 메뉴의 '결재'와 결재 승인 버튼을 구분한다. 과제 선택의 COM 응답을 잃으면 선택을 다시 실행하지 않고 창 닫힘과 같은 문서의 실제 과제 값을 재조회한다. 이 복구의 원본 포털 회귀시험은 102개, 공통 CLI는 19개 통과했다. 마지막 새 기안기 응답 시간 초과는 해결 완료로 처리하지 않는다.

모델 가중치를 새로 학습하거나 v1 어댑터를 교체하지 않았다. **필수 10과제의 실환경 전체 합격도, 기안 과제의 단독 상신·회수·삭제 합격도 선언하지 않는다.** 실제 인증정보·개인 식별값·서버 문서 ID·학교 화면·상세 도구 기록은 공개 저장소에 넣지 않는다.
