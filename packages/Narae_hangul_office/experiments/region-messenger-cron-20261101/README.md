# 지역 설정·메신저 CLI·예약 작업 검증

2026-11-01. 나래 오피스 0.13.0-preview.21의 기능·도구 개선이다. 이 작업에서 모델 가중치를 추가 학습하거나 필수 벤치 10개 전체의 실환경 합격을 선언하지 않았다.

## 반영한 기능

- 일반 설정에서 17개 교육청 지역을 저장한다. 해당 지역 업무포털 주소와 메신저 도구를 선택하며, 다른 지역 인증정보를 재사용하지 않는다. 지역 변경은 다음 로그인 탭부터 적용한다.
- 충북 CBE 전용 CLI와 지역별 Windows UIA 연결 어댑터를 포함한다. 실제 시험 지역은 충북이다. [지역 메신저 CLI의 지원 범위](https://github.com/y5496694/narae-messenger-cli/blob/main/ANALYSIS.md)에 제품·공식 출처·설치물 확인과 미검증 항목을 구분했다.
- 일반 설정의 **카톡 프로그램 사용**으로 Kakao CLI 도구를 켠다. 나래 챗봇의 요청·연결·프롬프트는 유지하고 결과는 확인된 나와의 채팅으로 보낸다. 실패한 전달 때문에 PC 업무를 다시 실행하지 않는다.
- 본인 프로필의 **나와의 대화**, 또는 본인 프로필 이름으로 방을 열 수 있다. 전송 전 현재 계정·MemoChat 종류를 확인한다. 같은 제목의 다른 방이 있으면 이름으로 전송하지 않는다. 실제 카톡 전송 시험은 사용자 요청에 따라 다음 날로 남겼다.
- 설정의 **예약 작업**에서 cron 생성·조회·수정·삭제를 제공한다. 앱 실행 중 현재 AI·도구 승인 설정으로 처리하며 놓친 실행은 재시작 후 몰아서 실행하지 않는다.
- 카톡 나래 챗봇의 `cron`, `/cron`, `예약 목록`은 AI 업무를 만들지 않는 별도 조회 명령이다. 이 명령을 외부에서 쓰려면 중계 서버에도 같은 버전이 필요하다. 외부 서버 배포는 미확인이다.

지역별 전용 내부 프로토콜 17종을 완성한 상태는 아니다. 비충북 앱과 계정이 없는 지역은 공통 UIA 연결 단계이며 실제 읽기·전송을 검증하지 않았다. 카톡 나와의 채팅 실제 전달과 외부 챗봇 서버 배포도 완료로 처리하지 않았다. 기안의 실제 상신·회수·삭제 검증은 별도의 실행 기록으로 관리한다.

[검사 집계](regression.json), [나래4 단독 기안 재검증의 미통과 지점](../narae4-solo-draft-20261101/README.md)을 함께 확인한다. 작업용 모델과 독립 브라우저는 시행 종료 후 닫았다. 기존 업무 문서와 임시저장 검수 사본은 유지한다.
