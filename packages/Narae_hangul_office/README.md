# 나래 한글 오피스

**나래 한글 오피스**는 나래한글을 사용해 한글 문서를 읽고 작성·편집하며 문서용 AI를 연결하는 Windows 앱입니다.

에이전트 기능은 별도 앱 **[나래톡](https://github.com/y5496694/Narae_talk)**으로 분리했습니다. 나래톡은 **나래 시리즈를 사용하여 교육 업무를 포함한 다양한 업무를 도와주는 에이전트**입니다.

- 나래톡: 기본 친구 나래(전체 도구), CLI별 친구, 독립 대화창, 이름·직업·지역 프로필, AI·메신저·인증서·브라우저·예약 설정, 나래 모델 설치.
- 나래 한글 오피스: 나래한글 엔진 기반 HWP/HWPX 읽기·작성·편집·PDF와 문서 AI. 에이전트·메신저·인증서·예약 기능은 나래톡으로 이동했습니다.

나래톡 채팅에서는 확장자 제한 없이 파일을 드래그하거나 첨부 버튼으로 선택할 수 있습니다. 한 개의 HWP/HWPX 첨부는 문서 편집 대상으로 연결하며 원본을 보존하고 작업 폴더의 첨부 사본을 편집·재확인합니다.

나래톡의 나래교무 포탈(지역)은 해당 지역 업무포털 로그인과 나이스·에듀파인 진입을 먼저 확인하고 명령을 처리합니다. 유효한 업무 창을 재사용하며 필요한 로그인은 등록된 지역 보안 문서로 한 번 수행합니다. 보안 문서가 없거나 인증을 확인하지 못하면 먼저 직접 로그인을 요청하고, `로그인 완료`라는 답변 후 실제 화면을 재확인하여 원래 요청을 이어갑니다.

## 설치와 실행

Windows x64에서 **나래톡 설치.cmd** 또는 **설치.cmd**를 실행합니다. Node.js·Python·Electron은 설치기가 준비합니다. 한글 문서 작업에는 한컴오피스 한글을 먼저 설치하고 한 번 실행해야 합니다. 나래톡의 메신저·브라우저만 사용할 때는 한컴 설치를 요구하지 않습니다.

```powershell
# 나래톡
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/install.ps1 -Product Talk
# 나래 한글 오피스
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/install.ps1 -Product Office
```

D 드라이브가 있으면 `D:\Codex\apps`에 각각 설치합니다. `-InstallRoot`로 경로를 지정할 수 있습니다. 바탕화면의 **나래톡**과 **나래 한글 오피스**는 별도 아이콘으로 실행됩니다.

나래톡의 첫 화면에서 이름을 입력하고 시작하세요. 직업과 지역은 선택 목록에서 고르며 생략할 수 있습니다. 교사 + 충북을 선택하면 충북 업무포털·충북소통메신저·WXS·나래교무 친구가 자동 추가되고, 실제 업무포털도 충북 주소로 연결됩니다. 친구를 선택해 대화하고 더블클릭하면 별도 대화창을 엽니다. 설정에서 AI OAuth/API 연결, 나래1~4 다운로드·실행, 메신저, 인증서와 예약을 관리합니다. 로컬 프로필은 원격 계정 가입과 다릅니다.

오피스 설정에는 일반과 AI 연결만 남아 있습니다. 기존 문서 작업 방식은 유지합니다.

## 한컴 버전 호환

설치된 Windows용 한글을 자동 탐색하고, 여러 버전이면 최신 버전을 우선합니다. 기존 파일은 원래 열린 한글 창을 재사용합니다.

| 한컴오피스 한글 | 확인 범위 |
| --- | --- |
| 2024 | 실제 HWP/HWPX 본문·서식 편집, 저장 후 재열기, PDF 출력 검증 |
| 2022 | 실제 HWP/HWPX 본문·서식 편집, 저장 후 재열기, PDF 출력 검증 |
| 2020·2018·기타 Windows 버전 | 설치 경로 자동 탐색 및 COM 연동 대상. 실제 해당 버전의 기능 호환성은 미검증 |

다른 버전의 동작은 한글 COM 자동화·HWPX·PDF 출력 지원 여부와 보안 정책에 따라 달라집니다. 미리보기·PDF 출력에는 해당 한컴의 PDF 출력 기능과 `Hancom PDF` 프린터가 필요합니다. 다른 버전이나 별도 설치 경로를 지정하려면 `NARAE_HWP_EXE`를 실제 `Hwp.exe` 경로로 설정하세요.

## 문서 작업

1. **문서 열기**로 HWP/HWPX를 선택합니다. 미리보기는 설치된 한글로 출력한 실제 문서 쪽입니다.
2. AI에게 “이 문서의 오탈자를 고쳐 줘”, “제목을 17pt 굵게 바꿔 줘”처럼 요청합니다. 기존 파일은 실제 한글 창을 재사용하며, 편집하려고 별도의 빈 문서를 남기지 않습니다.
3. **한글에서 열기**로 직접 편집하거나, **현재 내용**으로 현재 열린 문서의 텍스트를 확인할 수 있습니다.
4. **미리보기**로 저장한 최신 내용을 확인합니다. 자동 저장을 끈 경우에는 한글에서 먼저 저장하세요. **PDF 사본**은 작업 폴더에 새 이름으로 저장합니다.
5. **새 한글 문서**에서 HWP/HWPX를 만들 수 있습니다. 표·그림을 포함한 문서는 AI에게 형식과 내용을 함께 지정하세요.

기존 문서의 편집 전 사본은 데이터 폴더의 `backups` 또는 `data/backups`에 보관합니다. 파일을 직접 편집할 때는 최신 해시를, 열린 문서를 편집할 때는 최신 내용과 원문 후보 수를 확인합니다. 미저장 문서를 파일 엔진으로 덮어쓰지 않습니다. 변경 추적 문서는 현재 한글의 텍스트와 네이티브 동작으로 처리합니다. 일부 작업이 실패하면 완료 단계와 백업을 알립니다.

지원 범위와 문제 해결은 [사용 안내](docs/사용안내.md)를 참조하세요. 모든 한글 기능을 대체하는 앱은 아니며 한컴오피스 한글 설치가 필요합니다.

## 저장과 계정

문서·대화·설정은 로컬에 저장합니다. 나래톡과 오피스는 데이터 저장소가 분리됩니다. API 키·OAuth 토큰·인증서 비밀번호는 Windows 사용자 암호화 저장소를 사용하고 화면에 다시 표시하지 않습니다. 클라우드 AI 사용 시 요청·처리한 내용은 선택한 제공자에 전달됩니다. 원격 메신저 연결은 설정에서 별도로 연결합니다.

## 개발과 검증

```powershell
npm ci
npm start
npm run start:talk
npm test
npm run test:talk:desktop
```

CLI는 문서 작업 `narae-office`, 에이전트 `narae-talk`으로 분리됩니다. 설치기는 두 앱의 별도 바로가기와 아이콘을 만듭니다. 원본 도구의 상세 절차와 모델 학습·라이선스·실환경 검증 범위는 `docs`와 `experiments`의 근거를 따릅니다.


나래톡의 개인 메모·달력·여러 CLI 친구 톡방·GitHub 업데이트와 지역 메신저 설치 기능은 [나래톡 저장소](https://github.com/y5496694/Narae_talk)에 있습니다. 이 저장소의 오피스 화면은 한글 문서와 문서용 AI 기능만 제공합니다.


나래톡 브라우저 친구의 일반 웹 검색·본문 읽기·출처 요약은 [나래톡 안내](https://github.com/y5496694/Narae_talk#브라우저-친구로-일반-웹-탐색)를 참조하세요.

나래톡의 메시지 처리 진행 패널, 드래그 파일·Ctrl+V 사진 첨부, 현재 창 안에서 전환하는 달력 화면도 나래톡에서 사용합니다. 오피스의 문서 전용 화면은 유지합니다.

나래톡 하단은 캘린더의 이번 주 일정 배너를 제공하며, 날짜마다 등록된 일정 개수를 표시합니다. 배너에서 현재 창의 달력으로 전환할 수 있습니다.

나래톡의 이지에듀 친구는 현재 로그인과 한국 시간의 요청 기간으로 일정을 한 번 조회해 표시합니다. 메시지 오른쪽의 마우스 오버 복사 버튼도 나래톡에서 제공합니다.

나래톡의 브라우저 이동은 승인·진행 상태 알림으로 취소되지 않으며, 네이버 홈에서 뉴스홈 링크로 이동하는 요청과 기사 요약 요청을 구분합니다. 이지에듀 조회의 간단·간략·타이틀 옵션은 날짜·분류·제목만 표시합니다.

나래톡의 소통메신저는 최근 5개 제목·개수 지정, 기본 한 달의 쪽지·대화 검색, 번호 선택, 본문·첨부 확인, 실제 창 열기와 파일 저장을 제공합니다. 내 조직 우선 수신자 검색과 동명이인 번호 선택, 지정 조직·첨부를 지키는 단일 전송도 나래톡에서 처리합니다.
