AI 연결

사용할 AI를 선택하고 아래에서 연결을 설정하세요.

나래AI 모델

나래3을 추천합니다. 사용을 누르면 선택한 모델 하나만 이 PC에서 실행합니다.

폴더를 바꾸어도 기존 모델은 이동하거나 삭제하지 않습니다. 실행 중인 AI를 먼저 중지하세요.

GPT 연결

사용할 AI와 연결 방식을 선택하세요. OAuth와 API 설정은 각각 보관합니다.

계정 토큰과 API 키는 Windows 사용자 암호화 저장소에 보관합니다. 다른 PC에서는 계정을 다시 연결하세요.

다른 로컬 AI 서버 연결

Ollama·LM Studio 등에서 OpenAI 호환 서버를 실행한 뒤 연결하세요. JSON Schema 응답을 지원해야 합니다.

메신저

메신저를 선택해 이 PC의 나래 에이전트와 연결하세요.

텔레그램 · 내 PC 연결

BotFather에서 전용 봇을 만든 뒤 토큰을 등록하세요. 토큰은 이 Windows 사용자의 암호화 저장소에 보관합니다.

연결 링크는 10분간 유효하며 한 개인 채팅만 연결합니다. HWP·HWPX 첨부, /files, /get 파일명, /cancel을 사용할 수 있습니다. PC 앱이 켜져 있어야 하며 도구 실행 승인은 이 PC의 일반 설정을 따릅니다.

카카오톡 · 내 PC 연결

카톡의 업무 요청을 이 PC의 나래 오피스로 전달합니다. PC와 이 앱이 켜져 있어야 합니다. 한 계정에는 PC 한 대를 연결합니다.

연결 안 됨

요청과 답변, 처리한 문서 내용은 카카오·중계 서버와 선택한 AI를 통과할 수 있습니다. 학교 로그인·인증서·AI 계정 토큰은 이 PC에 둡니다. 작업 폴더 밖 접근·임의 명령 실행은 허용하지 않으며, 도구 실행 시 승인창을 표시하며, 설정 → 일반에서 자동 허용으로 바꿀 수 있습니다.
