    일치하는 안내가 없습니다. 다른 검색어나 전체 영역으로 찾아보세요.

    업무포털 인증서

    나이스·K-에듀파인 로그인에 사용할 인증서 정보를 등록하거나 수정하세요. 인증서 파일은 현재 위치에서 사용합니다.

    교육청: · 지역 변경은 일반 설정에서 저장하세요.

    디스크 이름 또는 드라이브 중 하나를 입력하세요.

    비밀번호는 현재 Windows 사용자만 복호화할 수 있게 암호화해 저장합니다. 저장된 비밀번호는 표시하지 않으며, 수정 시 비워 두면 기존 값을 유지합니다.

    일반

    프로필과 도구 연결, 작업 저장 방식을 설정하세요.

    내 프로필

    카카오톡 CLI로 나와의 채팅에 에이전트 결과를 보냅니다.

    카카오톡·텔레그램 연결과 업무 세션 연장을 유지합니다. 완전히 종료하려면 트레이 아이콘 메뉴에서 종료하세요.

    문서 변경, 브라우저 조작, 메신저 발송에 적용합니다. 설정은 이 PC에 저장됩니다.

    다음 요청을 기다리는 동안 10분마다 기존 창의 연장 버튼을 누르고 남은 시간을 확인합니다. 작업 중에는 잠시 대기하며, 앱을 종료하거나 로그아웃하면 연장하지 않습니다.

    업무 브라우저

    기본은 나래 전용 브라우저입니다. 평소 사용하던 Chrome의 탭과 분리해서 업무를 진행합니다.

    이 옵션을 체크하고 확장 연결을 설정한 경우에만 기존 탭을 사용합니다. 연결을 해제해도 Chrome과 열린 탭은 남습니다.

    1. 아래 설치 버튼으로 Playwright 확장을 Chrome에 추가합니다.
    2. Chrome의 확장 아이콘 → Playwright 상태 화면에서 PLAYWRIGHT_MCP_EXTENSION_TOKEN 값을 복사합니다.
    3. 아래에 붙여 넣고 저장하면 다음 브라우저 작업부터 해당 설정으로 자동 연결합니다.

    프로필을 지정하려면 chrome://version의 프로필 경로에서 마지막 이름을 입력하세요. 토큰은 같은 프로필의 값을 사용합니다. 입력값은 이 PC에 암호화해 저장하며, 비워 둔 토큰은 기존 값을 유지합니다.

    문서와 대화는 이 컴퓨터에 보관합니다.

    예약 작업

    나래톡가 실행 중일 때 현재 AI와 도구 승인 설정으로 처리합니다. PC가 꺼졌거나 다른 작업 중이면 놓친 실행을 나중에 몰아서 처리하지 않습니다. 카톡 나래 챗봇에서 ‘cron’을 보내 목록을 조회할 수 있습니다.

    예: 0 8 * * 1-5 → 평일 오전 8시. 요일 0은 일요일입니다.

    AI 연결

    사용할 AI를 선택하고 아래에서 연결을 설정하세요.

    나래AI 모델

    기본 모델은 나래4입니다. 설치하면 본체·학습 어댑터·시각 프로젝터·판단기를 함께 받습니다. 사용을 누르면 선택한 모델을 이 PC에서 실행합니다.

    폴더를 바꾸어도 기존 모델은 이동하거나 삭제하지 않습니다. 실행 중인 AI를 먼저 중지하세요.

    GPT 연결

    사용할 AI와 연결 방식을 선택하세요. OAuth와 API 설정은 각각 보관합니다.

    계정 토큰과 API 키는 Windows 사용자 암호화 저장소에 보관합니다. 다른 PC에서는 계정을 다시 연결하세요.

    다른 로컬 AI 서버 연결

    Ollama·LM Studio 등에서 OpenAI 호환 서버를 실행한 뒤 연결하세요. JSON Schema 응답을 지원해야 합니다.

    메신저

    충북소통메신저는 이 PC의 원래 로그인 상태를 사용합니다. 지역 메신저는 일반 설정의 교육청을 선택하세요. 친구 목록에서 해당 친구를 열면 CLI로 대화할 수 있습니다.

    메신저를 선택해 이 PC의 나래 에이전트와 연결하세요.

    텔레그램 · 내 PC 연결

    BotFather에서 전용 봇을 만든 뒤 토큰을 등록하세요. 토큰은 이 Windows 사용자의 암호화 저장소에 보관합니다.

    연결 링크는 10분간 유효하며 한 개인 채팅만 연결합니다. HWP·HWPX 첨부, /files, /get 파일명, /cancel을 사용할 수 있습니다. PC 앱이 켜져 있어야 하며 도구 실행 승인은 이 PC의 일반 설정을 따릅니다.

    카카오톡 · 내 PC 연결

    나래 챗봇의 업무 요청과 프롬프트를 유지하고, 처리 결과는 카카오톡 CLI로 나와의 채팅에 보냅니다. 일반 설정의 카톡 프로그램 사용을 켜고 본인 계정으로 PC 카카오톡에 로그인하세요. PC와 나래톡가 켜져 있어야 합니다. 챗봇에서 cron 또는 예약 목록으로 예약을 조회할 수 있습니다.

    연결 안 됨

    요청과 답변, 처리한 문서 내용은 카카오·중계 서버와 선택한 AI를 통과할 수 있습니다. 학교 로그인·인증서·AI 계정 토큰은 이 PC에 둡니다. 작업 폴더 밖 접근·임의 명령 실행은 허용하지 않으며, 도구 실행 시 승인창을 표시하며, 설정 → 일반에서 자동 허용으로 바꿀 수 있습니다.
