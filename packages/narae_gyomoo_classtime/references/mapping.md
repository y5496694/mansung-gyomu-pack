# AI 셀 매핑 규약

매핑은 과목을 AI가 재작성한 결과가 아니라, **원본에서 어느 셀을 읽을지** 정한 지도다. 따라서 오탈자나 장소 정보도 `raw`로 보존된다. 행/열 방향, 학년 수, 반 이름, 교시 수를 제한하지 않는다. 예제 주소를 실제 양식의 주소로 바꾼다.

`inspect`는 전체 XLSX의 모든 탭, 비어 있지 않은 셀과 병합 영역을 로컬 파일에 기록한다. `inspection.txt`에서 원본에 있는 학급 목록을 먼저 별도로 적고 이후 각 학급 셀 위치를 매핑한다. 시간표 외 시수 요약표, 전담교사표, 과거 학년도표는 구별하고 coverage.notes에 제외 이유를 기록한다. 숨김 시트도 확인하되 그 자체로 최신이라고 판단하지 않는다.

`data/candidate.json`의 구조:

```json
{
  "snapshot_hash": "source.snapshot.json의 source_hash",
  "plans": [{
    "academic_year": 2026,
    "semester": 2,
    "selection_reason": "문서 제목의 2026과 2학기 탭을 확인했다.",
    "term_evidence": [
      {"sheet": "@workbook", "cell": "@title", "value": "실제 문서 제목"},
      {"sheet": "2학기", "cell": "@name", "value": "2학기"}
    ],
    "weekdays": ["월", "화", "수", "목", "금"],
    "periods": [1, 2, 3, 4, 5, 6, 7, 8],
    "coverage": {
      "reviewed_all_sheets": true,
      "class_keys": [["1", "1"]],
      "notes": "원본의 학급 헤더 전체를 확인. 다른 학년도 탭과 교사별 표는 제외."
    },
    "classes": [{
      "grade": "1",
      "class": "1",
      "label": "1학년 1반",
      "sheet": "2학기",
      "anchors": [{"cell": "C1", "value": "1학년"}, {"cell": "C2", "value": "1"}],
      "days": {
        "월": ["C3", "C4", "C5", "C6", "C7", "C8", "C9", "C10"],
        "화": ["D3", "D4", "D5", "D6", "D7", "D8", "D9", "D10"],
        "수": ["E3", "E4", "E5", "E6", "E7", "E8", "E9", "E10"],
        "목": ["F3", "F4", "F5", "F6", "F7", "F8", "F9", "F10"],
        "금": ["G3", "G4", "G5", "G6", "G7", "G8", "G9", "G10"]
      }
    }]
  }]
}
```

- `academic_year`, `semester`는 원본/사용자 근거에 따른다. 문서 제목과 개별 탭의 연도가 다르면 개별 표 제목·내용의 구체적 연도를 우선하며 선택 이유를 남긴다. 복수의 후보가 있으면 시행일 등 근거를 검토하고 해결되지 않는 충돌은 질의한다.
- `term_evidence`: `@workbook`은 다운로드된 실제 문서 제목, `@name`은 실제 탭 이름이다. 일반 셀 주소도 가능하다. 선택 근거를 덧붙이되 value는 원문 그대로다.
- `coverage.class_keys`: 배치 매핑 전에 원본에서 발견한 전체 `[학년, 반]` 목록이다. 추출 학급 목록과 일치해야 한다. 학년/반은 문자열이므로 7학년, 유치원, 가반 등도 가능하다. 같은 표의 모든 학급이 포함되어야 한다.
- `periods`: 실제 표에 있는 교시를 오름차순으로 적는다. 8교시까지 또는 그 이상도 가능하다. 모든 학급은 이 공통 교시 수만큼 각 요일에 주소를 가진다.
- 수업 셀이 비었어도 실제 셀 주소를 적는다. 원본에 해당 칸 자체가 없는 경우에만 `null`을 적어 `unmapped`로 남긴다. 빈칸을 앞 교시 과목으로 채우지 않는다. `blank`도 자동으로 수업 없음으로 판단하지 않는다.
- 병합은 XLSX의 정확한 병합 범위 내에서만 왼쪽 위 값으로 해석한다. 병합된 과목이 여러 교시를 차지한다면 각 교시 주소를 배치해 같은 원문을 읽을 수 있다. 여러 반 공통 표도 각 반을 명시적으로 포함한다.
- `anchors`: 원본의 학년/반 헤더를 둘 다 포함한다. 병합 영역 안의 주소도 가능하다. 요일/교시 행열은 실제 표를 읽고 주소에 정확히 반영한다. 모든 비수업 셀과 병합, 전체 탭 목록이 구조 지문에 포함되므로 새 학급·요일·교시가 추가되면 재검토한다.
- `accept`는 검토한 스냅샷의 해시가 일치하는지 확인한다. 과목 값만 바뀌면 자동 갱신하며, 헤더나 바깥 셀 또는 병합 배치가 바뀌면 갱신을 멈추고 마지막 성공 데이터를 보존한다. 주석 등 비수업 셀 변경도 재검토를 유발할 수 있다.

갱신 결과 `data/current.json`에는 `classes[].days[요일][]`에 `period`, `raw`, `subject`, `detail`, `status`, `source.sheet`, `source.cell`, `source.anchor`가 있다. `source_hash`, `fetched_at`, `academic_year`, `semester`도 기록한다. 실제 링크·시트 ID는 공개 JSON과 HTML에 넣지 않는다. 괄호 부가정보는 원문과 함께 보존되며 교사명/장소 등을 임의 확정하지 않는다.
