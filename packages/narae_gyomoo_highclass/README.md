# 나래교무 하이클래스

[하이클래스(HiClass)](https://www.hiclass.net/)에서 교직원의 학급 공지와 학부모 소통을 돕는 Codex 스킬입니다. 사용자의 계정과 브라우저 컨트롤을 사용합니다.

## 지원 업무

- 교직원 로그인과 대상 학교·학년도·학급 확인
- 알림장 검색·조회·요약, 공지 초안 준비
- 읽음·미열람 현황 확인과 푸시 발송 단계 구분
- 하이톡 기존 대화 조회와 1:1 답장 준비
- 각 개인에게 보내는 일괄메시지, 교사만 발언하는 단체 공지방 구분
- 예약 연락 준비와 게시·전송 직전 정지

완료 단계가 불명확하면 게시·전송 직전까지 준비합니다. 실제 게시·발송·예약은 사용자가 명확하게 요청한 범위와 실행 도구의 확인 정책을 따릅니다. “조회만”, “작성하지 마”라는 요청에서는 시험용 문구도 입력하지 않습니다.

## 설치

저장소를 내려받고 `skills/narae-gyomu-hiclass` 폴더를 Codex의 사용자 스킬 디렉터리에 복사합니다. `$CODEX_HOME`을 별도로 지정했다면 그 아래 `skills`를 사용하며, 기본 위치는 `~/.codex/skills`입니다.

Windows 기본 설치 결과는 다음과 같습니다.

```text
%USERPROFILE%\.codex\skills\narae-gyomu-hiclass\SKILL.md
```

브라우저 컨트롤이 연결되어 있고, 사용할 하이클래스 교직원 계정으로 로그인할 수 있어야 합니다. 비밀번호나 세션 토큰을 이 저장소에 넣지 않습니다.

## 사용 예

```text
$narae-gyomu-hiclass 우리 반 알림장을 확인해 줘. 글은 작성하지 마.
```

```text
$narae-gyomu-hiclass 내일 준비물 공지를 학부모만 대상으로 작성해 줘.
준비물은 색연필과 풀이고, 게시하기 전에 멈춰 줘.
```

```text
$narae-gyomu-hiclass 지정한 학부모와의 최근 하이톡을 확인하고 답장 초안을 보여 줘.
메시지는 보내지 마.
```

## 검증 범위

2026년 10월 15일 PC 웹에서 교직원 구글 로그인, 클래스 진입, 기존 알림장·읽음 현황·하이톡 대화 조회와 빈 작성·선택 양식의 표시를 확인했습니다. 스킬 형식, 문서 링크, UTF-8/YAML과 배포 파일도 점검했습니다.

이 확인 과정에서 **제목·본문·답장 입력, 파일 업로드, 임시저장, 단체방 생성, 실제 게시·발송·예약은 실행하지 않았습니다.** 실제 입력·전송의 성공을 보장하는 테스트 결과는 아닙니다. 학교·권한·화면 개편에 따라 실행 시 현재 UI를 다시 확인합니다.

실제 학생·학부모 이름, 대화 원문, 비공개 학급 식별자와 로그인 정보는 배포 파일에 포함하지 않습니다.
